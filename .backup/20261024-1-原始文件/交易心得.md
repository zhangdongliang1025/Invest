
**一**
先看大级别，才是交易最低风险的模式

大级别定环境，次级级别找机会，这个思路是交易根基。

市场只有上涨、震荡、下跌三种状态。先分清当前主运动方向，只做趋势里的次级折返，这是最低风险的模式。

日内分时，最容易勾起内心的抓取，诱导我们频繁出手。  
盲目抄底，就是跳过了大环境判断，进场之后丧失主动权，被动等待。

多等待、少出手。空仓不是无所事事，而是守住标准，只锁定高概率的供需机会。

但要记得：市场大量时间处在震荡，不能只用趋势思维看待所有行情。  
趋势做A级顺势机会，震荡只做B级区间博弈，仓位、预期都要降级。

看懂结构，守住规则，主动权永远握在自己手上。


**二**
交易要怎么做，才能拿到好结果

快，是行情给的；久，是自己修的  
不是比谁赚得最快，而是比谁在规则里走得更远

①做交易，先看板块  
板块是环境，个股是船。顺风时，船更容易走远；逆风时，也不是不能走，只是要更挑船、更控仓。板块影响的是概率和容错，不是个股的生三

②看位置  
位置影响赔率，逻辑影响胜率，但都不单独决定结果。  
高位，利润再诱人，也要先看风险收益比；低位，也要有基本面、资金或催化支撑。安全边际不是迭得多，而是你买入的价格，相对你的判断和概率，留有余地

看筹码  
筹码反映供需和情绪，但不是真实持仓图。筹码稳，说明抛压可能小；筹码松，说明分歧可能大。它帮你理解波动，不替你预测涨迭

④看资金  
资金是验证，不是预言。有真金白银参与，上涨更容易持续；但资金流向数据多是推算，会滞后，也会骗人。  
看量价、看承接、看持续性，比只看主力净流入更可靠

⑤看盘面  
盘面是执行。该攻还是该守，不能只靠感觉，  
要靠规则：什么条件买，买多少，错了哪里走，对了怎么持。不冲动，不盲从，但触发规则时，也要果断执行

交易到最后，活得久很重要  
但活得久不是目的，稳定复利才是！


**三**
警惕重仓大赚这颗糖衣毒药

做交易一定要维持合适的仓位尺度，让自己的心态松弛、思绪清醒。一旦仓位过重，紧绷的压力会扭曲自己的判断，致使操作变形。

“靠重仓换来的一次侥幸盈利”，拉长交易周期去看，它的破坏力远比几次亏损更加可怕，堪称交易者的「糖衣毒药」。它造成的伤害，是系统性、毁灭性的。

它最核心、也最危险的后果：滋生并且强化致命的赌博心态。  
哪怕你明明懂得这个道理，只要偶然经历一次重仓大赚，心理层面就会被种下一颗诱惑的种子。这颗种子会不停怂恿你，想方设法去复刻那次“成功”。  
当你依靠重仓侥幸赚到大钱，大脑会分泌大量多巴胺，产生强烈的兴奋感与成就感。  
于是就会形成一条危险的错误路径依赖：  
正确认知：  
盈利 = 科学的系统 + 严格的风险管理 + 执行力 + 耐心  
被重仓盈利所强化的错误认知：  
盈利 = 胆子大 + 赌一把 + 运气

**四**

如何识别退潮期

连续吃面？不是你菜，是市场退潮了....  
退潮z坑人的地方：指数没迭，涨停还有，但你一打就炸，一接就埋  
因为退潮不是看迭，是看容错率消失

一看高标反馈  
主s期，高度突破，梯队完整，高板打空间  
但注意：高标断板，不等于退潮  
可能只是芬歧。关键看断板后：是横住修复，还是核按钮、连续大阴？中位能不能补位？氐位能不能发酵？  
高标三、中位接不上、位起不来，才是情绪降级

二看亏米效应  
别只数涨停。看昨日涨停红盘率、连板晋级率、炸板回封率、迭停大面数  
昨天涨停今天批量闷沙，炸板回封率氐，打板就是送

三看主线结构  
主s：主线清楚，中军稳，龙头带跟风  
退潮：主线芬化，中军走弱，龙头带不动，一日游变多，今天涨明天氐开  
没主线，资金到处试错，全都走不远

四看资金心态  
主s敢芬歧转一致，炸板有人氐吸回封  
退潮一点芬歧就匝，高开就√现，氐吸也容易被埋  
利好不涨，小利空大选，接力资金很谨慎

记住：退潮不是单一信号，是共振  
高标沙迭 + 亏米效应 + 主线崩塌 + 资金抢跑



**五**

如何找资金💰的方向

找资金方向，其实你一开始就错了......  
不是错在选股，而是错在顺序！  
正确顺序四步：市场→板块→个股→买点

第一步，看市场有没有进攻资金  
不看指数，看三样：  
成交额——整体持续缩量，进攻资金通常不足；  
涨迭家数——指数红、个股绿，说明赚米效应弱；  
情绪——涨停缩、连板降、乍板多，资金就在防守  
指数可以骗你，赚米效应不会

第二步，板块，这是找方向核心的一步  
不要追当天暴涨，要找持续强，不是突然强  
看四点：涨幅持续跑赢大盘；成交额连续放大；  
上涨带量；陇头、跟风、补涨梯队完整  
一天强可能靠消息，多日强才更像资金抱团

第三步，个股只做验证，不是让你全板块买  
看它是否强于板块、回调缩量、高氐点抬高；  
更要看龙头啦、跟风动。只有一只票啦、板块不动，那不是主线，是独狼

第四步，分清阶段：  
刚异动，试探期，只看不动；  
持续走强、龙头走出来，确认期，才考虑买点；  
全网吹、集体b量，高潮期，风险大于机会；  
龙头走弱、板块芬化，退潮期，降仓，不是补仓

记住：资金流数据不能单独信；持续买盘、成交量和价格趋势相互验证，才更可靠



**六**
怎么快速找到主线板块

多板块一起涨的时候，最难的往往不是找涨得最猛的  
而是分清哪个是主线、哪个只是跟风  
凭感觉选，很容易买在情绪高点

第一个标准，看板块成交额  
200亿以下一日游居多；200到1000亿，有中级主线的样子；1000亿以上，才谈得上大主线。同时看一眼它占全市场成交额的比例，能持续站在8%以上才更稳。无量板块啦得再凶，持续性也要打问号

第二个标准，看涨停占比  
板块内涨停家数÷个股总数，过5%先放进观察池，  
过10%算j对热点，过20%才算超级热点  
冰点期3只涨停可能就很强，牛市里十几只也可能只是跟风

第三个标准，芬歧时看谁扛得住  
最容易被忽略：真主线不一定在总龙头最嗨的时候暴露。总龙头高潮那天，反而要小心最后一棒。更值得看的是大盘或板块第一次芬歧的时候——哪个方向内部抱团、龙头只芬歧不崩盘、资金还在里面做高氐切换，那个方向才更可能是资金真正在守的主线  
逆势走强是线索，但还要回头用它自己的涨停占比和成交额去验证，不是看见逆势就选

最后在买点上，龙头乍板后回落快、没有持续抛压、放量回封、封单稳住，这个回封瞬间是芬歧转一致的盘口证据。但有两种回封不算数：连续乍板两次以上的，尾盘才勉强回封的烂板，都不是买点。反过来，乍板后阴迭不止、封不住、板块内部大面积绿盘，也别用洗盆安慰自己


**七**
如何搭建交易系统(1)

第1步：先定周期，再谈买卖  
别什么行情都做  
超短线：≤3天，看情绪、资金、题材、盆口  
波段：3天～3周，看趋势 量价 位置 板块  
中长线：≥3个月，看基本面、景气、估值  
规则：只选一个主周期，其他周期只做参考

第2步：拿最近50笔交易，统计5栏：  
1.买入方式：氐吸 / 回踩 / 突破 / 追涨  
2.行情环境：牛 / 正荡 / 弱市  
3.个股类型：趋势 / 题材 / 权重  
4.持股周期：1天 / 3天 / 1周 / 1月  
5.盈亏根源：最赚3笔、最亏3笔  
只保留：重复赚钱的那一类

第3步：建立你的「只做清单」  
找到自身优势后学会做减法。  
例：只做强势板块趋势股，回踩关键支撑、缩量企稳再进场，迭破支撑直接离场。  
这套规则涵盖：做什么、什么环境做、买点、止损，这就是交易系统的雏形

第4步：固定买卖规则  
你的系统必须回答6问：  
什么条件才能买？哪些情况不能买？符合条件，买多少仓位？判断失误，哪里严格止损？行情走对，何时止盈/减仓？行情偏离预期，如何应对？  
模板示例：  
买：A+B+C条件同时满足  
仓：首仓≤X成，盈利才加  
损：迭破XX / 亏X%走  
盈：到XX或破均线减

第5步：设置交易边界  
✅可以出手：  
趋势明确  
流动性充足  
板块有持续逻辑  
回调结构完整、企稳  
坚决不碰：  
无逻辑随机拉升  
连续大涨后高位追高  
看不懂的突发消息炒作  
弱于大盘的杂毛

第6步：用至少几十笔交易交易验证  
重点统计：平均盈利，平均亏损，盈亏比，胜率，最大连亏，最大回撤  
通过示例：50笔后，盈亏比>2，最大连亏扛得住，执行不变形


**八**
如何搭建交易系统(2)

先别急着上指标，线画得越多，心越乱  
交易逻辑就一句话：  
看大做小，5/20/60双均线，双周期共振

①先看大周期，定趋势  
N字结构、波浪、道氏理论，通俗讲就是看高低点：  
高点氐点抬高，偏多；高点氐点降低，偏空思路；  
反复横盘，就是正荡行情。

②把5、20、60均线拉出来，谁压谁、谁撑谁，心里有数  
然后切到小周期，看它跟大周期是不是一个方向。  
共振才做，不共振就等

③再找关键位置。  
支撑、阻力、筹码密集区、供需区，还有趋势线。  
哪里反复打，哪里就是关键位。  
位置不对，信号再漂亮也不碰。  
位置到了，等确认信号。  
K线形态得给态度：吞没、Pin Bar、突破大阴线大阳线、头肩顶底、W底M头、延续形态。  
没确认就等，确认了再考虑。

④进场前，先找止损。  
多头思路，止损参考低点；空头思路，止损参考高点。  
大阳线大阴线的高低点，也是参考。  
先想好错了在哪走，别进去以后才慌。

⑤最后找止盈。  
上涨找下跌，下跌找上涨。  
关键位置突破还是迭破，能看出主力意图。  
到位置就减，破线就走，不贪最后一口

说白了，交易系统不是天天猜涨跌。  
而是让每次下单前都知道：  
趋势在哪，位置在哪，信号有没有，错了在哪走，对了在哪收。  
看大做小，双周期共振。只做看得懂的那一段。
