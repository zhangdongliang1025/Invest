# 全局标签字典

> 版本 v1.1 · 2026-10-24
> 这是全库唯一的标签权威来源。新增标签必须先写进这里，再使用。
> v1.1 变更：启用 `futures`（有道云「投资笔记」中的股指期货仓位/风控素材需要）。
> 命名规范：英文小写 + 短横线，不用中文、下划线、驼峰。

## 使用规则

1. 所有标签写在 frontmatter 的 `tags:` 数组里，正文不写行内标签。
2. 每份素材/策略笔记至少 1 个内容类型 + 1 个状态。
3. 状态标签互斥，一个文件只能有一个。
4. 交易风格、资产品类可叠加；通用方法可不写品类，或写 `multi-asset`。
5. 作者、时间、来源不造标签，写进 frontmatter 的 `source:` / `imported:` 字段。
6. `00-索引与模板` 下的管理笔记不打内容标签，避免污染筛选结果。

## 一、内容类型标签

| 标签 | 释义 | 什么时候打 |
|---|---|---|
| `trade-mode` | 交易模式：一套完整的进出场逻辑 | 有环境判断 + 进出场 + 仓位思路的成套打法 |
| `indicator` | 指标/信号方法 | 讲一个或一组可测量指标怎么算、怎么读、阈值多少 |
| `market-view` | 市场观点 | 对某个时点/某段行情的判断、板块观点、盘面解读 |
| `trading-psychology` | 交易心理与认知 | 纪律、情绪、心法、行为金融、认知偏差 |
| `book-note` | 书籍/长文精读笔记 | 来源是一本书、一篇长文、一门课程的系统笔记 |
| `video-note` | 视频/直播转写 | 来源是短视频、直播、播客的转写稿，可与其它类型叠加 |
| `knowledge-note` | 基础知识整理 | 科普性、事实性、方法性知识 |
| `data-list` | 标的池/代码表/清单 | ETF 池、股票池、代码对照表、参数表 |
| `risk-management` | 风控与资金管理 | 止损、仓位、盈亏比、回撤控制这类主题 |
| `strategy-card` | 自研策略卡 | `21-策略卡片` 里的成品策略卡，专属标签 |
| `backtest` | 回测/统计验证 | `22-回测与验证` 里的回测报告、参数检验 |
| `journal` | 复盘日志 | `23-复盘记录` 里的日/周/月复盘、交易日志 |
| `principle` | 自研原则/框架 | `25-原则与认知` 里自己提炼的跨策略原则 |

## 二、交易风格标签

| 标签 | 释义 | 什么时候打 |
|---|---|---|
| `trend-follow` | 趋势跟踪 | 顺势、突破、均线多头排列、只做趋势中的回调 |
| `swing-trade` | 波段交易 | 持有数日到数周，吃一段主升/主跌 |
| `short-term` | 短线/日内 | 持仓 1–3 天或日内，追强势、打板、高频滚动 |
| `mean-reversion` | 均值回归/逆向 | 超跌反弹、情绪极值反转、偏离修复 |
| `rotation` | 行业/风格轮动 | 按板块强弱、资金流向切换行业或 ETF |
| `multi-timeframe` | 多周期共振 | 大级别定方向、小级别找入场 |
| `position` | 中长线配置/持有 | 按月/年持有，重基本面与估值 |

预留（未启用，出现对应素材后再加入本表）：`event-driven`、`quant`。

## 三、资产品类标签

| 标签 | 释义 | 什么时候打 |
|---|---|---|
| `stock` | A 股个股 | 内容涉及选股、个股买卖 |
| `etf` | ETF/场内基金 | 行业 ETF、宽基 ETF 的选择与轮动 |
| `index` | 大盘指数 | 上证、沪深 300、创业板等指数层面的判断 |
| `option` | 期权 | PCR、隐含波动率、期权策略 |
| `multi-asset` | 通用/跨资产 | 方法或心理类内容，不限标的 |
| `futures` | 期货 | 股指/商品期货合约、保证金、基差、杠杆与移仓逻辑 |

预留（未启用）：`convertible-bond`。

## 四、状态标签（互斥，一个文件只能有一个）

| 标签 | 释义 | 什么时候打 | 流转去向 |
|---|---|---|---|
| `unverified` | 未验证：外部观点或未证实的直觉 | 所有新入库素材默认状态 | → `to-backtest` 或 `deprecated` |
| `to-backtest` | 待回测：已整理成可检验假设 | 已抽出明确入场/出场规则，排队等回测 | → `testing` |
| `testing` | 验证中：回测中或小仓实盘 | 回测方案在跑，或极小仓位试单 | → `verified` 或 `deprecated` |
| `verified` | 已验证：有证据支持，可纳入体系 | 回测 + 样本外/实盘至少一项通过，并已写进策略卡 | 失效后转 `deprecated` |
| `deprecated` | 废弃：已证伪或失效 | 回测不通过、逻辑被推翻、环境消失 | 移入 `99-归档` |
| `reference` | 参考资料：不属于策略，无需验证 | 心理、基础知识、标的清单、交易规则、复盘日志 | 长期保留 |

### 状态流转

```text
unverified ──> to-backtest ──> testing ──> verified
     │              │             │
     └──────────────┴─────────────┴──────> deprecated ──> 99-归档

reference：独立分支，不进入验证流程
```

## 五、frontmatter 标准写法

```yaml
---
title: "课程笔记：均线波段"
source: "抖音 @某某"
imported: 2026-10-24
status: unverified
tags: [trade-mode, video-note, swing-trade, stock, unverified]
---
```

常见组合：

- 外部波段模式：`[trade-mode, swing-trade, stock, unverified]`
- 指标类视频：`[indicator, video-note, option, index, unverified]`
- 书籍心理笔记：`[book-note, trading-psychology, multi-asset, reference]`
- 已验证策略卡：`[strategy-card, rotation, etf, verified]`
- 回测报告：`[backtest, rotation, etf, testing]`
- 复盘日志：`[journal, multi-asset, reference]`
