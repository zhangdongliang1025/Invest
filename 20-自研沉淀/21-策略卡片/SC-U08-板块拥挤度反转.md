# SC-U08 板块拥挤度反转

> 存放位置：`20-自研沉淀/21-策略卡片`
> 状态 `testing`：回测已通过（IS + OOS），进入小仓/模拟跟踪阶段，尚未有实盘样本。

## 一句话假设

当某个行业的**成交占比偏离自己过去半年水平**达到极端（`RATIO_SCORE > 300`）时，该行业在未来 20 个交易日跑输其它行业；**回避该行业 / 换到其它行业**即可获得相对收益。

## 适用环境

- 市场温度：不限；牛市里拥挤板块同样跑输（2019、2021、2024 的触发样本都在上涨环境）
- 波动率：不限
- 流动性：行业需有可交易的 ETF 或成分股篮子；成交额太小的行业不适用
- **明确不适用的情况**：
  - 政策发布日、重大事件日（触发集中在油气、种植业、贵金属、燃气这类事件驱动行业，信号可能只是事件后回落）
  - 只用「3 年历史分位」判定拥挤的用法——该口径已验证无效

## 入场规则

1. 每日收盘后计算各行业 `RATIO = 行业成交额 / 全市场成交额 × 100`
2. `RATIO_SCORE = (RATIO − MA120(RATIO)) / MA120(RATIO) × 100`
3. `RATIO_SCORE > 300` 的行业进入「禁止新增持仓」名单
4. 次日开盘前执行：名单内的行业不建仓；已持仓的行业减至 0
5. 名单有效期 20 个交易日（同行业冷却 20 天）

## 出场规则

- 止损：不适用（本策略只做多侧回避）
- 止盈：20 个交易日后自动解除
- 时间止损：即出场条件本身

## 仓位与风控

- 单笔风险预算：不适用（不新建仓）
- 首仓 / 加仓：不适用
- 最大同时持仓：沿用组合层规则（见 [[G02-仓位与单笔风险预算]]）
- 组合相关性约束：被回避的行业数超过 3 个时（全市场同时拥挤），整体降仓而不是全押其它行业

## 失效条件

出现以下任一信号立即停用：

- `RATIO_SCORE > 100` 的事件连续 3 次 20 日超额为正
- 触发行业的 20 日超额中位数回到 0 以上
- 交易成本上升到 0.4% 以上（信号幅度会被吃掉）
- 市场整体进入「所有行业同时极度放量」的状态（此时占比失去区分度）

## 证据

- 回测报告：[[BT-U08-板块拥挤度]]
- 样本：2019-01-02 → 2026-10-23，1,892 个交易日，90 个同花顺行业指数
- 样本外结果：OOS（2023-01 → 2026-10）20 日超额 **−5.09%（t=−2.24，n=21）**，方向与样本内一致且更强
- 样本内结果：IS（2019–2022）20 日超额 −3.74%（t=−3.13，n=24）
- 日期聚类 bootstrap 95% CI：[−6.85%, −1.80%]（不含 0，43 个独立事件日）
- 胜率 / 盈亏比 / 期望 / 最大回撤：77.8% 事件为负超额；单次 20 日超额均值 −4.37%、中位数 −4.90%；组合层面 MDD 未测（本策略为回避侧）
- 实盘样本数与区间：**无**（下一步：模拟盘 3 个月，记录每次触发的行业与后续 20 日表现）

## 待验证的边界

1. **五维合成 `CROWD` 未测**（[[B03-行业拥挤度综合指标]] 仍为 `unverified`）；本卡只承诺 `RATIO_SCORE` 单维度有效
2. **「事件驱动 vs 拥挤」未分离**：需要在触发样本里剔除商品/政策事件行业后复核
3. **无法做空**：收益来自相对切换，不是绝对收益；大盘上涨时该策略大概率跑输指数
4. **多重检验**：试过 8 个偏离度阈值 + 4 个分位阈值；`>100`–`>200` 区间需要独立样本复核
