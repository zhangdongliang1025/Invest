# PM01 基准线仓位模型

> 来源：[[股指期货基准线持仓策略]]（以上一波熊市大底设定基准线、100%/80%/60% 三档仓位、保证金预留公式、作者 1 月爆仓后的策略更新）。
> 回答的问题：**带杠杆的仓位能开到多大？** 它是**杠杆仓位上限模型**，不是选股模型。

## 1. 模型陈述

**基准线 = 上一波熊市的大底。** 以基准线为 100% 仓位标尺，按当前标的相对基准线的位置反推「能开多少手」。

```text
基准线 B        = 上一波熊市大底（如 IM 用 4177）
一手保证金 M    = 标的现价 − B  （多头；贴水利润另计）
100% 仓位的合约数 N100 = 总权益 / M

当前仓位档位：
  常规上行        100% 基准线  = N100 手
  估值警戒线触发   80% 基准线  = 0.8 × N100 手
  极端情况        60% 基准线  = 0.6 × N100 手（仓位底线）
```

原文的算例（IM）：

| 项目 | 数值 |
|---|---:|
| 基准线（上一波熊市大底） | 4177 |
| IM 现货 | 5700 |
| 一手权益（12 万 + (5700−4177)×200） | 42 万 |
| 总权益 | 4200 万 |
| 100% 基准线持仓 | 100 手 IM（11400 万） |
| 实际持仓 | 15440 万 = **135% 基准线** |
| 底部位（8.28 / 9.13）峰值仓位 | 500% 基准线 |

## 2. 三档仓位的含义

| 档位 | 触发条件 | 原文理由 |
|---|---|---|
| **100%** | 默认上行持仓 | 既保证参与大级别行情，又不脱离安全边际 |
| **80%** | 涨到「估值指标内的单波上涨警戒线」（约 15 个估值指标综合判断） | 锁定部分利润，但不清仓——「万一这次就是那 1% 概率的扶摇直上的一波流牛市，那么清仓的踏空风险，将是不可承受的」 |
| **60%** | 上行周期的仓位底线 | 「抓大放小」：小周期仓位把控提高总利润率和盈利 EV，但绝不错过牛市 |

> **80% 而不是清仓**是这套模型的核心设计：原文明确它是在**胜率与 EV 之间做博弈**，而不是简单的风险厌恶。

## 3. 原文给出的两条补充规则

1. **短期涨多了，没必要立马硬加，应该减。**
2. **上行周期（牛市），应该略超基准线而不是低于基准线。** （即在底部区域可以超配——作者 9.13 那天做到 500% 基准线。）

## 4. 极端情形

1. **跳空穿越基准线**：股指期货有夜盘与跳空，基准线是「上一波大底」，不是「这一次的大底」。极端行情中基准线本身会被击穿——**这就是作者 1 月爆仓的经历，也是他改造模型的原因**。
2. **上一波大底本身选错**：若上一波熊市是个异常浅的底，基准线会偏高 → 100% 仓位被高估；若上一波是异常深的底，基准线偏低 → 模型过于保守。
3. **单品种集中**：作者的组合是 IM + IF + IO + MO 四个品种叠加，本质是**用不同品种的基差与贴水分散**，单品种不适用。
4. **贴水利润与权利金**：原文说「以上一波大底为基准线 + 贴水利润」，即基准线的保护还要叠加贴水收益；贴水收敛时这层保护消失。
5. **60% 底线是极端值，不是常态**：它对应「上行周期」的仓位下限，不适用于熊市。
6. **保证金上调**：交易所调整保证金比例时，同样权益能开的手数下降，模型必须用**动态保证金**而非固定值。

## 5. 数据与实现

- 基准线：各品种（IF/IC/IM/IH）的历史熊市最低点，需人工判定并记录日期。
- 权益：`账户净值 + 闲置资金`（原文的口径）。
- 一手权益：`现价 − 基准线` × 合约乘数 + 保证金占用；贴水单独计入。
- 回测需要：合约结算价 + 分钟行情（模拟逐笔穿越）+ 历年保证金规则 + 涨跌停与夜盘。
- **强平模拟**：必须在基准线被击穿时模拟强平，否则模型结论无效。

## 6. 回测与验证

- 假设（对应 [[待验证策略看板]] U17）：以「上一波熊市大底」设定期货持仓基准线并据此预留保证金，历史回测中 90% 以上的回撤路径不触发强平，爆仓率显著低于固定比例保证金法。
- 方法：
  1. 对 IF/IC/IM/IH 各自取历次熊市底，建立基准线序列；
  2. 按 100% / 80% / 60% 三档规则生成每日目标手数；
  3. 对照组：**固定比例保证金法**（如固定 2 倍杠杆）与**固定比例手数法**；
  4. 统计强平次数、爆仓率、最大回撤、收益、收益/回撤比、保证金占用曲线。
- 必须注意：本模型的核心收益来自「底部区域的超配」，而底部是事后知道的。**回测里的基准线不能是事后画出来的最低点，必须用当时可见的信息（如「上一波熊市大底」在当时确实是已知的）**，否则是未来函数。
- 样本：2010 年股指期货上市至今，按品种分别统计。
- 结论只写「通过 / 不通过 / 样本不足」。

### 待验证的边界

1. **基准线的选点规则**：作者是人工判定的，规则化后（如「过去 N 年最低结算价」）是否等价，未知。
2. **80% 警戒线依赖「15 个估值指标综合判断」**，这 15 个指标是什么、权重如何，素材里没有——**这是模型不可复现的部分**，也是本条假设最难验证的地方。
3. **品种间的相关性**：IM/IF/IO/MO 并不是四个独立仓位，基准线保护在同向行情下会同时失效。
4. **期权（IO/MO）的处理**：期权是买方权利金，不是线性保证金，基准线逻辑需要重新推导。
