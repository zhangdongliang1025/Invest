# A01 涨跌家数与市场宽度

> 来源：[[情绪指标]]（通达信公式）、[[交易心得]]（指数与个股背离）、[[@Fioona交易模式的简单分享]]（看涨跌家数判断市场温度）。
> 回答的问题：**今天是个股普涨/普跌，还是只有指数在动？** 它衡量「赚钱面」的宽度，不预测点位。

## 1. 定义

| 符号 | 含义 | 口径 |
|---|---|---|
| `ADV` | 上涨家数 | 当日收盘价高于前收的股票数 |
| `DEC` | 下跌家数 | 当日收盘价低于前收的股票数 |
| `FLAT` | 平盘家数 | 收盘价等于前收（含停牌，若软件计入） |
| `N` | 有效样本数 | `ADV+DEC+FLAT`，剔除停牌与上市前 5 日新股 |
| `AMT` | 全市场成交额 | 沪深两市合计，单位亿元 |

`DYNAINFO(60)` = 上涨家数，`DYNAINFO(61)` = 下跌家数，`DYNAINFO(62)` = 总成交额（元）。这三个是**盘中动态值**，收盘前会一直变。

## 2. 公式

```text
ADR           = ADV / DEC
log_ADR       = ln((ADV+1) / (DEC+1))          // DEC=0 时避免除零
宽度 Breadth  = ADV − DEC
宽度占比      = (ADV − DEC) / N
上涨占比      = ADV / (ADV + DEC)               // 剔除平盘，推荐主口径
涨幅中位数    = median(个股当日涨跌幅)           // 比家数更抗权重干扰
```

辅助：

```text
5日宽度均值   = MA(上涨占比, 5)
60日分位      = percentile_rank(上涨占比, 60)
```

> 为什么主口径剔除平盘：停牌股、ST 股、北交所会稀释分母；`ADV/(ADV+DEC)` 只统计「有方向」的股票。

## 3. 判断标准

### 3.1 原文绝对阈值（仅保留，不直接用于今天）

[[情绪指标]] 的公式画了 5 条线：

| 线 | 上涨家数 | 标签 |
|---|---:|---|
| 极热 | 3240 | 极热区 |
| 过热 | 2880 | 过热区 |
| 微热 | 1880 | 微热区 |
| 冰点 | 720 | 冰点区 |
| 恐慌 | 360 | 恐慌区 |

**关键校准问题**：这组数字更像是在 A 股约 3500 只股票时代设计的。按 3500 只换算，分别是 **93% / 82% / 54% / 21% / 10%**，五个档位才连贯；若按今天 5000+ 只直接除，3240 只剩 65%，会把「普涨」误判成「极热」。所以：

- 原文绝对值只能作为**历史坐标**；
- 实盘用「上涨占比」或「60 日分位」，不要用固定家数。

### 3.2 口径（已回测，仅作状态描述）

| 上涨占比 | 状态 | 含义 | 动作倾向 |
|---|---|---|---|
| ≥85% | 极热 / 普涨 | 几乎全员上涨，常出现在政策日、超跌反弹首日 | 不追高；持有者考虑兑现一部分 |
| 70%–85% | 过热 | 赚钱面很宽，但也接近短期情绪高点 | 持有，收紧止损 |
| 50%–70% | 偏暖 / 中性 | 结构性行情正常区间 | 按个股规则做 |
| 30%–50% | 偏冷 | 多数股票下跌，指数可能被权重撑住 | 降仓，不接弱势股 |
| 15%–30% | 冰点 | 亏钱效应明显，常伴跌停增加 | 等 2–3 日确认，不左侧重仓 |
| <15% | 恐慌 | 千股跌停级别的极端 | 只做观察；反弹需跌停数下降 + 涨停回升确认 |

分位口径（更稳）：

| 60 日分位 | 状态 |
|---|---|
| >95% | 极热 |
| 80%–95% | 偏热 |
| 20%–80% | 中性 |
| 5%–20% | 偏冷 |
| <5% | 恐慌 |

### 3.3 指数与个股背离（[[交易心得]] 的核心用法）

| 指数 | 上涨占比 | 解读 | 动作 |
|---|---|---|---|
| 涨 | >70% | 普涨，宽度确认 | 正常参与 |
| 涨 | <40% | 权重护盘、指数失真，小票在失血 | 不把指数红当安全，检查持仓 |
| 跌 | >60% | 小票修复、风格切换，指数被权重拖累 | 观察是否新主线 |
| 跌 | <30% | 普跌，风险偏好收缩 | 降仓/空仓 |

> 一句话：**指数告诉你「面子」，涨跌家数告诉你「里子」。** 里子坏了，面子越红越要小心。

## 4. 极端情形

1. **千股跌停/涨停**：`ADV` 或 `DEC` 接近 0，ADR 失真；`上涨占比` 会贴到 0% 或 100%。此时指标只说明「极端」，不说明「反转」。2015-07、2020-02-03、2024-02 小微盘流动性危机都出现过类似形态。
2. **指数与宽度长期背离**：2024 年初权重护盘、微盘股崩跌，沪深 300 与中证 2000 的宽度完全不同。此时应分市值/板块看宽度，不能只看全市场。
3. **政策日高开低走**：2023-08-28 印花税下调，开盘普涨、收盘分化；盘中 `DYNAINFO` 的极热值不可靠，必须等收盘。
4. **样本扩容**：注册制后每年新增数百只股票，`N` 变大，固定家数阈值持续失真；新股前 5 日无涨跌幅，波动极端，应剔除。
5. **停牌/ST/北交所**：停牌计入平盘会稀释；ST 5% 涨跌幅、北交所 30% 涨跌幅会改变分布；最好分开统计。
6. **节前节后**：长假前成交额萎缩，宽度信号噪声大；节后首日受外盘影响，单日极值多，需 2–3 日确认。

## 5. 数据与实现

- 通达信：`DYNAINFO(60)`、`DYNAINFO(61)`、`DYNAINFO(62)`；`880005$C` 为市场情绪线，`880006` 的 `$C/$O` 可读涨停/跌停家数（不同版本字段可能不同，导入后先核对）。
- 自建：用全 A 日线（含退市股）按 `close > pre_close` 计数，能得到可回测的历史序列；比依赖软件动态函数更可靠。
- 复权：计算涨跌家数用**不复权**的当日涨跌幅；计算个股收益回测用**同一套复权**数据。
- 频率：日频；盘中版只用于观察，不进回测。

## 6. 回测与验证

- 假设（对应 [[待验证策略看板]] U07）：上涨占比进入极值区后，指数未来 5/10 日收益出现均值回归。
- 方法：按上涨占比分 5 组，统计未来 1/5/10/20 日指数收益、胜率、最大回撤；极值组单独看。
- 必须用 point-in-time 全 A 名单，含当时已上市、后来退市的股票；剔除上市前 5 日与停牌。
- 样本至少覆盖 2010–2026，并按 2015 杠杆牛/熊、2018 单边熊、2020 疫情、2024 小微盘危机分段。
- 结论只写「通过 / 不通过 / 样本不足」；不要用「感觉经常准」代替统计。

### 回测结论（2026-10-24）：均值回归主张不通过，指标本身有效

报告：[[BT-U07-涨跌家数极值]]｜看板：[[待验证策略看板]] U07

| 检验项 | 结果 |
|---|---|
| 样本 | 2022-08-08～2026-10-23，1019 个交易日，日均有效样本 5065 只 |
| 无条件 | 极值后 5/10/20 日 −0.04% / −0.01% / +0.12%，均不显著 |
| 高宽度（>85% / >90%） | 20 日 **+1.95% / +2.61%**，是**延续**而非反转 |
| 低宽度（<15% / <10%） | 20 日 +0.32% / +0.18%，不显著；<360 家去重后仅 9 次，**样本不足** |
| 结论 | **不通过**（恐慌侧同时样本不足） |

原文极值线的漂移实测：3240 家按今天 5065 只换算只剩 64% 宽度，触发 280 天（原按 93% 设计），已无区分度；360 家那条线数值仍有效但样本太少。

因此本页定位改变：**涨跌家数只用于描述「当前赚钱面宽窄」，不作反转择时。** 实盘用上涨占比或历史分位，不用固定家数；§3.2 的分档表只作状态标签。
