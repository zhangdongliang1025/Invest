# A02 涨停生态与连板指标

> 来源：[[交易心得]]（高标反馈、晋级率、炸板率、退潮四信号）、[[@Fioona交易模式的简单分享]]（1 进 2、二板铺 3–4 只、三四板去弱留强、高位放量分歧兑现）。
> 回答的问题：**短线资金的接力意愿还在不在？** 这是情绪周期最灵敏的一组指标。

## 1. 定义

| 符号 | 含义 | 口径 |
|---|---|---|
| `ZT` | 涨停家数 | 收盘价 = 当日涨停价 |
| `DT` | 跌停家数 | 收盘价 = 当日跌停价 |
| `ZB` | 炸板家数 | 盘中触及涨停、收盘未封住 |
| `N` | 有效样本数 | 剔除上市前 5 日新股、停牌股 |
| `H` | 最高板 | 当日涨停股中最大的连续涨停天数 |
| `ZT_N` | N 板家数 | 连续 N 个交易日收盘涨停 |
| `FIRST` | 首板家数 | 今日涨停且昨日未涨停 |

「板」的计数只数**收盘是否封住**；盘中触板不算连板。炸板后回封的股票计入 `ZT`，不计入 `ZB`。

## 2. 公式

```text
封板率        = ZT / (ZT + ZB)                 // ZT+ZB=0 时记 null，不记 0
炸板率        = ZB / (ZT + ZB)                 // = 1 − 封板率
涨停占比      = ZT / N
跌停占比      = DT / N
N板晋级率     = 今日(N+1)板家数 / 昨日N板家数
1进2晋级率    = 今日2板家数 / 昨日首板家数
昨日涨停红盘率 = 昨日涨停且今日收涨家数 / 昨日涨停且今日可交易家数
昨日涨停收盘溢价 = mean(今日收盘 / 昨日收盘 − 1)   // 昨日涨停股等权
昨日涨停开盘溢价 = mean(今日开盘 / 昨日收盘 − 1)
板块涨停占比  = 板块涨停家数 / 板块成分股数
```

**分母处理**：昨日 N 板股今天停牌的，从分母剔除并单独记录；退市/停牌造成的样本缺失不能当成「晋级失败」，否则会系统性低估晋级率。

## 3. 判断标准

### 3.1 单项阈值（原文 + 建议带）

| 指标 | 原文/常用阈值 | 建议分档（待回测） | 含义 |
|---|---|---|---|
| 封板率 | >70% 强势 | >75% 强；60%–75% 中性；<60% 弱；<50% 极弱 | 封住了多少触板资金 |
| 炸板率 | <20% 强；20%–30% 正常；>30% 弱 | >40% 极弱；35%–40% 冰点特征 | 触板资金的失败率 |
| 板块涨停占比 | >5% 观察；>10% 热点；>20% 超级热点 | 结合板块规模看分位 | 板块内部强度 |
| 板块成交额 | <200 亿一日游；200–1000 亿中级；>1000 亿大主线 | 占全市场 >8% 且持续 | 资金容量 |
| 昨日涨停收盘溢价 | <0 弱；>3% 强 | 结合 5 日均值 | 接力赚钱效应 |
| 1 进 2 晋级率 | 冰点 <20%；高潮 >50%–70% | 与全市场晋级率比较 | 低位接力意愿 |
| 最高板 `H` | 冰点 ≤3；高潮 >5–7 | 与 20 日分位比较 | 情绪高度 |

> 固定家数阈值会随市场扩容漂移。5000 只股票时，`ZT=80` 只占 1.6%；3500 只时代占 2.3%。优先看 `ZT/N` 与历史分位。

### 3.2 情绪阶段组合（必须多项共振）

| 阶段 | 涨停/跌停 | 最高板 | 封板/炸板 | 晋级率 | 昨日溢价 | 动作倾向 |
|---|---|---|---|---|---|---|
| 冰点 | `ZT<20` 或占比 <0.4%，`DT` 增多 | ≤3 | 炸板率 >35%–40% | 1进2 <20% | <0 | 空仓/只观察 |
| 修复 | `ZT` 回升到 20–50 | 3–4 | 炸板率 25%–35% | 20%–35% | 0–2% | 小仓试错，确认再加 |
| 发酵 | `ZT` 50–80，占比回升 | 4–6 | 封板率 >65% | 35%–50% | 2%–4% | 正常参与主线 |
| 高潮 | `ZT>80–100` | ≥6 | 封板率 >75% | >50% | >4% | 持有不追，准备兑现 |
| 分歧 | 涨停仍多，炸板率上升 | 高标断板 | 封板率下降 | 开始下降 | 溢价收窄 | 去弱留强，降仓 |
| 退潮 | `ZT<40` 且下降 | 高度下移 | 炸板率 >30% | <20% | <0 | 降仓/空仓，不补仓 |

**退潮不是单日信号**，[[交易心得]] 要求四项共振：高标杀跌 + 亏钱效应 + 主线崩塌 + 资金抢跑。至少看 2–3 个交易日。

### 3.3 高标反馈的读法

| 现象 | 解读 |
|---|---|
| 高标断板后横住、修复 | 分歧，不一定退潮 |
| 高标断板后核按钮、连续大阴 | 退潮确认概率高 |
| 中位股能补位、低位能发酵 | 梯队完整，情绪仍在 |
| 高标断、中位接不上、低位起不来 | 情绪降级 |
| 龙头带不动、跟风一日游 | 主线分化，降低预期 |

## 4. 极端情形

1. **一字板**：封板率很高，但买不到。`ZT` 里混入大量一字板会高估「可参与度」；应另算「一字板占比」和「封单额/流通市值」，回测中一律视为不可成交。
2. **20cm 与 10cm 混算**：创业板/科创板一个 20% 等于主板两个板，连板高度不可直接比较；主板、双创、ST、北交所应分组统计。
3. **ST 与新股**：ST 主板 ±5%，新股前 5 日无涨跌幅；不剔除会污染涨停/连板统计。2023-04-10 起主板注册制新股前 5 日无涨跌幅。
4. **涨停数为 0**：`封板率` 分母为 0，必须记 null；不要写成 0% 或 100%。
5. **政策日/救市日**：涨停家数可能瞬间翻倍，次日又归零；单日极值不能当周期拐点，需 2–3 日确认。
6. **尾盘偷袭板**：14:50 后封板，封单薄，次日溢价不可靠；可加「封板时间」和「封单额」过滤。
7. **炸板回封**：同一只股票反复开板再封，记入 `ZT` 但质量差；高位反复开板是 [[@Fioona交易模式的简单分享]] 的兑现信号。

## 5. 数据与实现

- 涨停价：主板 `round(前收×1.10, 2)`；创业板/科创板 `×1.20`；ST 主板 `×1.05`；北交所 `×1.30`。按交易所规则四舍五入到分，别用浮点直接比。
- 炸板：`high == 涨停价 and close < 涨停价`；若 `close == 涨停价`，无论开板多少次都算封住。
- 连板：从当日往前逐日检查 `close == 当日涨停价`；遇到停牌日按「停牌不中断」还是「中断」需先定口径，建议停牌中断并单独标注。
- 数据源：通达信 `880006`（涨停/跌停家数，字段因版本而异）、连板网、乐咕乐股、韭研公社；自建时用全 A 日线 + 涨跌停价规则重算，最可控。
- 板块涨停占比：用当日板块成分股，不能用今天的成分回测过去。

## 6. 回测与验证

- 假设（[[待验证策略看板]] U05）：冰点/退潮组合出现后降仓，能降低回撤；修复/发酵组合出现后参与，风险调整收益更高。
- 1 进 2 策略单独测：昨日首板 → 今日开盘买入（一字板跳过）→ 按次日/固定持有期卖出；统计胜率、盈亏比、最大连亏。
- 必须扣：佣金、卖出印花税 0.05%、滑点；T+1 下当日买入不能当日卖。
- 不可成交处理：开盘一字板、全天封死涨停的样本剔除，不许用收盘价假装成交。
- 分段：2015 杠杆牛、2018 单边熊、2021 结构市、2024-02 小微盘危机、2024-09 政策反转。
- 样本 <30 次的阶段结论只记「样本不足」。
