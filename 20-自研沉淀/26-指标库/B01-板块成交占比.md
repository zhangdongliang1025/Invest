# B01 板块成交占比

> 来源：[[拥挤度指标]]（把「成交占比」作为拥挤度核心维度）、[[交易心得]]（板块成交额 200 亿/1000 亿、占比 8%）。
> 回答的问题：**全市场的钱，有多少比例挤在这一个板块里？** 占比比绝对成交额更能识别「抱团到极致」。

## 1. 定义

| 符号 | 含义 |
|---|---|
| `AMT_s` | 板块当日成交额（亿元） |
| `AMT_m` | 全市场当日成交额（沪深两市合计，亿元） |
| `RATIO` | 板块成交额占全市场比重（%） |
| `RATIO_MA` | `RATIO` 的 120 日均值 |
| `RATIO_PCT` | `RATIO` 近 3 年历史分位（0–100） |

分母必须统一：要么都用「沪深两市」，要么都用「全 A 含北交所」；换分母会让占比整体平移，历史比较失效。

## 2. 公式

```text
RATIO        = AMT_s / AMT_m × 100
RATIO_MA     = MA(RATIO, 120)
RATIO_SCORE  = (RATIO − RATIO_MA) / RATIO_MA × 100
RATIO_PCT    = percentile_rank(RATIO, 3年)
占比/市值比  = RATIO / (板块自由流通市值 / 全市场自由流通市值 × 100)
```

`RATIO_SCORE` 是「相对自己过去半年」的偏离，`RATIO_PCT` 是「相对自己过去三年」的位置。前者灵敏，后者抗漂移。

## 3. 判断标准

### 3.1 原文阈值

| 口径 | 阈值 | 原文含义 |
|---|---|---|
| 板块成交额 | <200 亿 | 一日游居多 |
| 板块成交额 | 200–1000 亿 | 有中级主线的样子 |
| 板块成交额 | >1000 亿 | 才谈得上大主线 |
| 成交占比 | 持续 >8% | 更稳的主线 |
| 单一行业占比 | >10%–15% | 历史极限区（2021 新能源、2023 AI 等） |
| 占比回落 | 3 天内下降 >30% | 资金集体退潮的确认信号 |
| 历史分位 | >95% | 即使综合拥挤度未到 300，也应高度警惕 |

### 3.2 建议分档（分位口径已回测：无效，仅作参考）

| `RATIO_PCT` | `RATIO_SCORE` | 状态 | 动作倾向 |
|---|---|---|---|
| >95% | >100 | 极端拥挤 | 不追；持有者分批兑现 |
| 80%–95% | 30–100 | 偏热 | 持有但收紧止损 |
| 50%–80% | −30–30 | 正常 | 按个股规则 |
| 20%–50% | −60–−30 | 偏冷 | 等催化，不左侧 |
| <20% | <−60 | 冰点 | 观察，等放量转强 |

### 3.3 量价配合

| 价格 | 占比 | 解读 |
|---|---|---|
| 涨 | 升 | 资金真金白银流入，趋势健康 |
| 涨 | 降 | 缩量上涨/分歧，追高赔率差 |
| 跌 | 升 | 放量出逃，最危险 |
| 跌 | 降 | 缩量回调，可能只是洗盘 |

## 4. 极端情形

1. **板块定义变了**：概念板块频繁新增/调整成分，历史占比不可比；行业指数相对稳定，优先用行业指数。
2. **市值占比不同**：同样 8% 的成交占比，对小市值板块是极端拥挤，对银行这种大市值板块可能只是正常。加看「占比/自由流通市值占比」；公开研究常用 2.6–2.8 倍作为历史高位参考，但口径依赖样本，需自己复算。
3. **单一行业 vs 大主题**：2021 新能源、2023 AI 的「10%–15% 极限」是单一行业口径；若把 TMT 多个子行业加总，历史上限会更高（有研究口径到 30%–40%）。不要把两个口径混用。
4. **全面牛市/全面熊市**：所有板块成交额一起放大或萎缩，占比的区分度下降；此时看相对分位，不看绝对值。
5. **政策日/单日暴量**：单日占比冲高可能是事件驱动，次日回落；至少看 3 日持续性。
6. **ETF 被动资金**：ETF 申赎会让板块成交额突然放大，但不代表主动资金看多；需区分。
7. **分母缺失**：部分软件 `INDEXAMOUNT` 返回 0；用沪深两市成交额手动拼接，或固定分母口径，不能今天用一个、明天用另一个。

## 5. 数据与实现

- 通达信：板块指数 `AMOUNT`；全市场用 `INDEXAMOUNT`（部分版本不支持），或 `SHAMOUNT+SZAMOUNT` 自定义。
- Wind/Choice：行业指数成交额、自由流通市值；板块成分按当日。
- 自建：用个股日线按板块分类加总，能得到 point-in-time 历史；板块分类用申万/中信一级，避免概念板块漂移。
- 频率：日频；周频可降噪。

## 6. 回测与验证

- 假设（[[待验证策略看板]] U08）：板块成交占比突破 3 年 95% 分位后，该板块未来 20 日跑输全市场。
- 方法：按 `RATIO_PCT` 分 5 组，统计未来 5/20/60 日板块超额收益、胜率、最大回撤。
- 执行：收盘确认，次日用板块 ETF 或等权成分股开盘价；扣佣金/滑点；ETF 免印花税。
- 分段：2015、2021、2023、2024-09；至少留 2 年样本外。
- 阈值敏感性：90%/95%/99% 分位都跑一遍，避免只挑一个好看的结果。

### 回测结论（2026-10-24）：偏离度口径通过，3 年分位口径不通过

报告：[[BT-U08-板块拥挤度]]｜看板：[[待验证策略看板]] U08｜策略卡：[[SC-U08-板块拥挤度反转]]

| 口径 | 结果 |
|---|---|
| `RATIO_SCORE > 300` | 45 次事件，20 日超额 **−4.37%（t=−3.56）**，77.8% 为负；bootstrap CI95 [−6.85%, −1.80%]；样本内 −3.74%、样本外 −5.09% |
| 阈值族 `>100`～`>300` | 全部显著为负（t = −4.18 ～ −2.77），不是单点拟合 |
| `RATIO_PCT > 0.90`～`>0.99` | 全部不显著（+0.06% ～ −0.07%），**分位口径无效** |

为什么分位失效：占比本身有长期漂移（板块生命周期、全市场成交额变化），3 年分位把「结构性抬升」误当成极端。**偏离度口径看「相对自己过去半年的偏离」，抗漂移；分位口径看「相对自己过去三年的位置」，不抗漂移。**

§3.1 原文阈值中的「持续 >8%」「单一行业 10%–15% 极限」本次未被检验；回测只覆盖 `RATIO_SCORE` 一个口径。
