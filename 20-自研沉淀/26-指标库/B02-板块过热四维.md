# B02 板块过热四维

> 来源：[[拥挤度指标]] 的四个原始维度：成交额偏离、换手率偏离、价格乖离率、相对大盘强弱偏离。
> 回答的问题：**这个板块是「真强」还是「涨透支了」？** 四个维度分别看量能、筹码、价格、超额收益。

## 1. 公式

```text
AMT_SCORE  = (AMT − MA(AMT,120)) / MA(AMT,120) × 100          // 成交额偏离
HSL_SCORE  = (HSL − MA(HSL,120)) / MA(HSL,120) × 100          // 换手率偏离
BIAS60     = (CLOSE − MA(CLOSE,60)) / MA(CLOSE,60) × 100       // 60日乖离
REL_RAW    = (CLOSE/REF(CLOSE,60) − 1)×100
           − (INDEXC/REF(INDEXC,60) − 1)×100                    // 60日超额收益（百分点）
REL_SCORE  = REL_RAW × 10                                      // 原文的放大系数
```

标准化版本（推荐用于加权）：

```text
Z_i = (X_i − mean_3y(X_i)) / std_3y(X_i)
```

`HSL` 为换手率；原文有 `IF(HSL>0, HSL, VOL/10000)` 的兼容写法，但 `VOL/10000` 与换手率量纲不同，只在软件缺字段时临时用，不能混进历史序列。

## 2. 四个维度各看什么

| 维度 | 公式 | 经济含义 | 过热读数 |
|---|---|---|---|
| 成交额偏离 | `AMT_SCORE` | 绝对量能是否异常放大 | >+2σ 或 >90% 分位 |
| 换手率偏离 | `HSL_SCORE` | 筹码交换是否过度 | >+2σ；低位板块尤其有效 |
| 价格乖离 | `BIAS60` | 涨幅相对 60 日均线是否透支 | >+2σ；原文指数口径 >20% 为热 |
| 相对强弱 | `REL_RAW` | 是否持续跑赢大盘 | >+2σ；转负是走弱信号 |

> `REL_SCORE` 的 ×10 只是把 1 个百分点超额放大成 10，方便和成交额偏离同图显示；它不是「10 倍重要」，加权时必须用标准化后的 `Z`。

## 3. 判断标准

### 3.1 单维分档（标准化后）

| `Z` | 状态 |
|---|---|
| >+2 | 极端过热 |
| +1 ~ +2 | 偏热 |
| −1 ~ +1 | 正常 |
| <−1 | 偏冷 |

### 3.2 组合判定

| 过热维度数 | 状态 | 动作倾向 |
|---|---|---|
| 4 个 | 极端拥挤 | 不追，兑现 |
| 3 个 | 过热 | 持有收紧，停止加仓 |
| 2 个 | 偏热 | 正常持有，观察背离 |
| 1 个 | 关注 | 按个股规则 |
| 0 个 | 正常/偏冷 | 等催化 |

### 3.3 背离读法

| 组合 | 含义 | 处理 |
|---|---|---|
| 价格↑ + 成交额↓ | 缩量上涨，承接减弱 | 不追高 |
| 价格↑ + 相对强弱↓ | 还在涨但跑输大盘 | 警惕风格切换 |
| 价格↓ + 换手率↑ | 放量下跌，筹码松动 | 减仓 |
| 价格↓ + 成交额↓ | 缩量回调 | 看支撑是否有效 |
| 乖离高 + 成交额低 | 价格透支但无量 | 最脆弱，优先减 |

## 4. 极端情形

1. **新板块历史不足**：120 日均线/3 年分位需要足够样本；新概念板块前 120 日只能看绝对值和短均线，不能硬套阈值。
2. **低换手板块**：银行、公用事业换手率天然低，微小变化就会让 `HSL_SCORE` 失真；改用成交额 + 相对强弱。
3. **全市场同涨同跌**：牛市里所有板块成交额都放大，绝对偏离失效；用「相对全市场」的 `REL_RAW` 和占比（[[B01-板块成交占比]]）。
4. **指数成分调整**：板块指数换成分、自由流通市值变化，会让 `BIAS60`、`HSL` 跳变；用 point-in-time 成分。
5. **单日事件**：政策、订单、并购消息造成一天暴量；看 3–5 日持续性和回踩承接，不看单日。
6. **20cm/ST 混入**：涨跌幅规则不同，换手率和乖离分布不同；分板块类型统计。
7. **A 型尖顶**：拥挤度见顶后常见「急涨—放量—连续阴跌」，[[拥挤度指标]] 的描述是「机构集中兑现、同向卖出，形成负反馈」。指标只能提示脆弱，不能精确抓顶。

## 5. 数据与实现

- 板块指数：申万/中信一级行业优先；概念板块仅作辅助。
- 换手率：`成交额/自由流通市值` 或软件 `HSL`；全市场换手率用于对照。
- 相对强弱：`INDEXC` 用同一板块的基准指数（如沪深 300 或中证 800），不要拿上证指数和成长板块比。
- 标准化窗口：3 年滚动，至少 500 个交易日；窗口太短会被极端值主导。
- 缺失值：停牌/无成交日不补 0，用前值或剔除。

## 6. 回测与验证

- 单维 IC：每个维度与未来 20 日板块超额收益的秩相关；IC 稳定才进入组合。
- 组合：按「过热维度数」分组，统计未来 5/20/60 日超额收益、胜率、最大回撤。
- 执行：收盘信号，次日板块 ETF 开盘；扣成本；ETF 流动性不足时用等权成分股模拟。
- 稳健性：1 年/3 年标准化窗口、Z 阈值 1.5/2/2.5 各跑一遍；避免只报最优。
- 分段：2015、2021、2023、2024-09；样本外验证。
