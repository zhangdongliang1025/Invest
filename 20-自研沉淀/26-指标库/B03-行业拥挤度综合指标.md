# B03 行业拥挤度综合指标

> 来源：[[拥挤度指标]] 的完整通达信公式（五维融合 + 成交占比）。
> 回答的问题：**这个板块的抱团程度，是否已经到了「稍有风吹草动就踩踏」的位置？**

## 1. 原始公式

```text
N:=60; M:=120;

AMT_SCORE   = (AMOUNT − MA(AMOUNT,M)) / MA(AMOUNT,M) × 100
HSL_SCORE   = (HSL − MA(HSL,M)) / MA(HSL,M) × 100
BIAS_SCORE  = (CLOSE − MA(CLOSE,N)) / MA(CLOSE,N) × 100
REL_SCORE   = [(CLOSE/REF(CLOSE,N) − 1)×100 − (INDEXC/REF(INDEXC,N) − 1)×100] × 10
RATIO       = AMOUNT / INDEXAMOUNT × 100
RATIO_SCORE = (RATIO − MA(RATIO,M)) / MA(RATIO,M) × 100

RAW_CROWD   = RATIO_SCORE×0.3 + AMT_SCORE×0.2 + HSL_SCORE×0.15
            + BIAS_SCORE×0.15 + REL_SCORE×0.2
拥挤度      = SMA(RAW_CROWD, 5, 1)
```

原文阈值线：`过热线 300`、`中性上 120`、`中性下 −80`。

## 2. 每个权重的含义

| 维度 | 权重 | 为什么 |
|---|---:|---|
| 成交占比偏离 `RATIO_SCORE` | 0.30 | 存量博弈里，占比比绝对成交额更能反映「钱被抽干」 |
| 成交额偏离 `AMT_SCORE` | 0.20 | 绝对量能放大，但会被全市场放量干扰 |
| 换手率偏离 `HSL_SCORE` | 0.15 | 筹码交换速度，反映分歧/接力 |
| 价格乖离 `BIAS_SCORE` | 0.15 | 涨幅透支程度 |
| 相对强弱 `REL_SCORE` | 0.20 | 是否持续跑赢大盘 |

## 3. 必须先修正的量纲问题

原文把五个不同量纲的分数直接加权：

- `RATIO_SCORE`、`AMT_SCORE`、`HSL_SCORE` 是「百分比偏离」，可到 ±100；
- `BIAS_SCORE` 是「价格偏离百分比」，通常 ±20；
- `REL_SCORE` 是「超额收益百分点 ×10」，可到 ±100。

结果：**成交占比和相对强弱实际主导，乖离率的 0.15 权重被稀释**。这不是说原文无效，而是说它的 300/120/−80 阈值只对这套原始量纲成立。

推荐标准化版：

```text
Z_i = (X_i − mean_3y(X_i)) / std_3y(X_i)      // 3年滚动，至少500个交易日
CROWD_Z = 0.3·Z_RATIO + 0.2·Z_AMT + 0.15·Z_HSL + 0.15·Z_BIAS + 0.2·Z_REL
拥挤度_Z = SMA(CROWD_Z, 5, 1)
```

标准化后阈值不能用 300/120/−80，改用：

| `CROWD_Z` | 状态 | 动作倾向 |
|---|---|---|
| >2.0 | 极端拥挤 | 不追，兑现 |
| 1.0–2.0 | 偏热 | 持有收紧 |
| −1.0–1.0 | 中性 | 按个股规则 |
| <−1.0 | 偏冷 | 观察，等催化 |

## 4. 判断标准（原始量纲）

| `拥挤度` | 状态 | 含义 |
|---|---|---|
| >300 | 过热 | 历史热门板块的极端区，警惕 A 型顶 |
| 120–300 | 中性上 | 偏热，持有但停止加仓 |
| −80–120 | 中性 | 正常波动 |
| <−80 | 中性下/冷 | 资金撤离或关注度低 |

辅助确认（[[拥挤度指标]] 的实战补充）：

1. `RATIO` 突破该板块近 3 年 95% 分位 → 即使综合值未到 300，也警惕；
2. `RATIO` 3 天内下降 >30% → 资金集体退潮的早期确认；
3. 价格创新高但 `CROWD` 不创新高 → 拥挤度顶背离，减弱；
4. 价格跌破 20 日线 + `CROWD` 从高位快速回落 → 退潮确认。

## 5. 极端情形

1. **阈值是拟合出来的**：300/120/−80 来自作者在热门行业上的测试，不是全市场通用常数。不同板块、不同年代必须重新校准。
2. **板块历史不足**：新概念板块没有 3 年数据，`MA120` 和分位都不可靠；至少积累 250 个交易日再使用。
3. **盘中重绘**：`SMA(...,5,1)` 含当前值，盘中会变；只用在收盘后，回测用收盘值。
4. **全市场暴涨/暴跌**：所有板块一起放量，占比和相对强弱失真；此时先看 [[A01-涨跌家数与市场宽度]] 判断环境。
5. **拥挤可以持续很久**：2015 上半年、2021 新能源、2023 AI 都出现过长期高位；拥挤度高是「风险上升」，不是「明天见顶」。
6. **退潮后的分化**：[[拥挤度指标]] 说「只有真正有业绩、有壁垒的龙头能稳住，后排杂毛直接腰斩」；指标只能提示板块风险，不能替代个股基本面。
7. **成交额分母不兼容**：`INDEXAMOUNT` 在部分通达信版本返回 0；改用沪深两市成交额，且历史序列必须同口径。

## 6. 回测与验证

- 假设（[[待验证策略看板]] U08）：`CROWD` 突破 300（或 `CROWD_Z>2`）后，板块未来 20 日超额收益为负、最大回撤显著高于基准。
- 分组：按 `CROWD` 分 5 组，统计未来 5/20/60 日超额收益、胜率、最大回撤；重点看最热组。
- 执行：收盘信号，次日板块 ETF 开盘；ETF 流动性不足时用等权成分股；扣佣金/滑点。
- 稳健性：原始量纲 vs 标准化量纲各跑一遍；权重扰动 ±0.05；阈值 90%/95%/99% 分位。
- 分段：2015、2021、2023、2024-09；至少 2 年样本外。
- 未来函数检查：`REF`/`MA` 不含未来；板块成分用当日；`INDEXC` 用当日收盘。

### 已测与未测（2026-10-24）

- **已测**：单维度 `RATIO_SCORE`（成交占比偏离度）**通过**——`>300` 后该板块未来 20 日超额 −4.37%（t=−3.56），见 [[BT-U08-板块拥挤度]]。
- **未测**：本页的五维合成 `CROWD`（`0.3·RATIO + 0.2·AMT + 0.15·HSL + 0.15·BIAS + 0.2·REL` 再 `SMA(5,1)`）。U08 只测了权重最高的那一维，**不能**把 U08 的结论直接搬到 `拥挤度 > 300` 上——权重与量纲会改变结果（见 §3）。
- **已失效**：§4 辅助确认第 1 条「`RATIO` 突破 3 年 95% 分位 → 警惕」在 U08 中全部不显著，应降级为无效信号。
- 因此本页维持 `unverified`，补测五维合成列在 [[P0-回测总览]] 的下一步队列（P1）。
