# B04 杠杆与资金流

> 来源：[[股市温度计（3个指标）]]（融资余额/流通市值）、[[期权PCR与大盘关系]]（ETF 净流入≠护盘、认沽成交≠做空）。
> 回答的问题：**市场的钱是自有资金还是借来的？ETF 的流入是真承接还是被动/套利？**

## 1. 杠杆指标

### 1.1 公式

```text
融资余额占比 = 融资余额 / A股流通市值 × 100%
融资买入占比 = 融资买入额 / 全市场成交额 × 100%
维持担保比例 = (现金 + 信用证券市值) / (融资买入金额 + 融券卖出市值 + 利息费用) × 100%
```

- 融资余额：交易所每日公布，T+1 可用；只覆盖**场内两融**，不含场外配资、收益互换、质押等隐性杠杆。
- 流通市值：用同一数据源的 A 股流通市值，别用总市值；口径变了历史比较失效。

### 1.2 判断标准

| 融资余额/流通市值 | 状态 | 含义 |
|---|---|---|
| <2% | 温和 | 杠杆不高，情绪偏谨慎 |
| 2%–3% | 中性 | 正常区间 |
| 3%–4% | 偏热 | 杠杆资金活跃，注意波动放大 |
| >4% | 极端 | 历史高位区，警惕去杠杆 |
| >4.5% | 危险 | 2015 年级别的杠杆压力区 |

| 融资买入额/成交额 | 状态 |
|---|---|
| <9% | 温和 |
| 9%–12% | 中性 |
| 12%–15% | 偏热 |
| >15% | 极端，短线风险高 |

| 维持担保比例 | 状态 |
|---|---|
| >300% | 安全 |
| 250%–300% | 关注 |
| 150%–250% | 偏紧 |
| 130%–150% | 警戒，可能被要求追保 |
| <130% | 强制平仓风险 |

> 公开数据坐标（2026-08）：融资余额/流通市值约 **2.69%**，处于中性偏上；2015 年峰值约 **4.27%–4.73%**（不同口径）。250% 是偏保守的预警线，行业通用的警戒/平仓线通常是 150%/130%，以开户券商合同为准。

## 2. ETF 资金流

### 2.1 公式

```text
单日净流入 = (今日份额 − 昨日份额) × 当日净值        // 或 × 收盘价，需固定口径
5日累计     = Σ 单日净流入（最近5日）
20日累计    = Σ 单日净流入（最近20日）
流入强度    = 单日净流入 / 基金规模 × 100%
```

### 2.2 读法

| 价格 | ETF 净流入 | 解读 |
|---|---|---|
| 涨 | 流入 | 资金确认，趋势健康 |
| 涨 | 流出 | 逢高赎回/套利，谨慎追高 |
| 跌 | 流入 | 可能是抄底、保险、套利或护盘，不等于见底 |
| 跌 | 流出 | 去杠杆/赎回，压力仍在 |

[[期权PCR与大盘关系]] 的三个提醒：

1. ETF 净流入多流向宽基，只托权重，不覆盖数千小票；「指数涨、个股跌」时不要把它当全市场承接。
2. 130 亿 ETF 是「现金资产」，14.5 亿期权是「带杠杆的风险敞口」，两者不可直接比较。
3. 公开数据无法区分国家队、保险、私募、套利资金；**ETF 净流入 ≠ 护盘**。

## 3. 组合判断

| 组合 | 状态 | 动作倾向 |
|---|---|---|
| 融资占比 <2% + 融资买入 <9% | 杠杆温和 | 正常 |
| 2%–3% + 9%–12% | 中性 | 正常 |
| 3%–4% + 12%–15% | 偏热 | 收紧止损，不追高 |
| >4% + >15% | 极端 | 降仓，防强制去杠杆 |
| 维持担保 <150% | 压力 | 减仓/补保证金 |
| ETF 流入 + 宽度弱 | 非见底信号 | 不抄底 |
| ETF 流入 + 宽度强 | 承接确认 | 可正常参与 |

## 4. 极端情形

1. **2015 去杠杆**：融资余额占流通市值升至 4% 以上，下跌触发平仓、平仓再下跌，形成负反馈；杠杆指标在高位钝化，不能等「跌了才跑」。
2. **2024-02 小微盘流动性危机**：宽基 ETF 有流入，但小票流动性枯竭；全市场宽度与 ETF 流向背离，单看 ETF 会误判。
3. **数据滞后**：融资余额 T+1，ETF 份额 T+1；用当日收盘价配昨日杠杆数据，回测必须滞后一天。
4. **场外杠杆不可见**：配资、收益互换、质押、结构化产品不在两融数据里；2015 年的真实杠杆高于两融口径。
5. **ETF 份额变化不等于资金流**：份额拆分、分红再投资、做市商申赎都会改变份额；优先用「份额变化×净值」，并核对公告。
6. **宽基 vs 行业**：宽基流入可能是护盘/配置，行业流入可能是主题交易；两者不能合并成一个「资金流」信号。
7. **低利率环境**：融资成本下降会提高合理杠杆中枢，历史 3% 的阈值可能不再适用；用分位数校准。

## 5. 数据与实现

- 两融：交易所官网、东方财富「融资融券」、Wind；每日 T+1。
- 流通市值：中证/申万口径；保持同一数据源。
- ETF：基金公司公告、交易所、天天基金；份额与净值分别取，别用二级市场价格替代净值。
- 维持担保比例：只在券商 APP 可见个人账户；市场整体用两融余额/流通市值近似，不能直接等同。
- 频率：日频（杠杆）、周频（ETF 累计流）。

## 6. 回测与验证

- 杠杆假设：融资余额占比突破 4%（或 90% 分位）后，未来 20/60 日指数最大回撤显著放大。
- ETF 假设：宽基 ETF 连续 5 日净流入且市场宽度同步改善，未来 20 日收益优于「只有流入、宽度恶化」的情形。
- 方法：事件研究 + 分组；信号用 T+1 可得数据，T+2 开盘执行；扣成本。
- 分段：2015、2018、2024-02、2024-09；至少 2 年样本外。
- 注意：杠杆与 ETF 流都是「同步/滞后」指标，不适合单独做左侧抄底。
