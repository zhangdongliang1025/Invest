# C05 牛熊周期四阶段定位

> 来源：[[0-A股市场能不能赚钱？]]（「天时地利人和」框架、A股牛熊四阶段、衰退阶段大胆买 / 过热阶段看情绪）、[[1-股票市场上涨的原因是什么？]]（经济 + 流动性 + 购买意愿 + 低估值四个条件）、[[通胀周期的投资核心思路（上）]]（美元加息/降息周期与资产价格路径）。
> 回答的问题：**现在是牛熊周期的哪一段？这段该做什么动作？** 它是**状态定位器**，输出的是「仓位与动作」，不是「明天涨跌」。

## 1. 核心框架：三因三态

原文把 A 股牛熊拆成三个可观测的驱动，再组合出四个阶段：

| 驱动 | 原文名 | 可观测代理 | 方向含义 |
|---|---|---|---|
| 天时 | 经济增长 | GDP 同比增速（及环比方向） | 经济上行 → 企业盈利上行 |
| 地利 | 估值 | 宽基 PE/PB 历史分位 | 估值下行 → 股价被压制 |
| 人和 | 流动性 | 两市成交额（及其历史分位） | 成交萎缩 → 增量资金退场 |

三因各分「强 / 弱 / 稳」三态，组合出四阶段：

| 阶段 | 天时（经济） | 地利（估值） | 人和（流动性） | 市场特征 |
|---|---|---|---|---|
| **过热** | 强劲 | 上行 | 强 | 完全的牛市；成交额破万亿、估值水涨船高 |
| **下行** | 仍强劲 | 下行 | 弱 | 牛市的落幕；聪明钱先走，风格剧烈分化 |
| **衰退** | 低迷 | 下行 | 弱 | 完全的熊市；成交极度萎缩、估值极便宜 |
| **复苏** | 低迷但企稳 | 上行 | 强 | 政策见效，估值先行；没有主线，轮动极快 |

> 原文的口径是「经济/流动性/估值三态组合出四阶段」。注意「复苏」和「下行」在经济上都是低迷/强劲的延续，区别在**流动性与估值先行转向**——复苏是流动性先好转，下行是流动性先萎缩。

## 2. 公式

```text
GDP 方向  g_dir  = sign(GDP同比的 3 期变化率)      → +1 / 0 / −1
估值方向  v_dir  = sign(宽基 PE 分位的 60 期变化)   → +1 / 0 / −1
流动性方向 l_dir = sign(成交额的 60 期变化)         → +1 / 0 / −1

阶段判定：
  过热：g_dir=+1 且 v_dir=+1 且 l_dir=+1
  下行：g_dir=+1 且 v_dir=−1 且 l_dir=−1
  衰退：g_dir=−1 且 v_dir=−1 且 l_dir=−1
  复苏：g_dir=−1 且 v_dir=+1 且 l_dir=+1
  混沌：其余组合（现实中占比不小，不要硬套）
```

估值与流动性必须用**分位数**而非绝对值，这是本库已被回测验证过的结论（见 §5）。

## 3. 判断标准

### 3.1 原文给出的估值档位动作

| 宽基估值分位 | 动作 |
|---|---|
| >60% | 开始警惕，考虑减仓 |
| >80% | 准备随时清仓离场 |
| 创历史新高 | 坚决离场，不回头 |

### 3.2 四阶段对应的动作（原文）

| 阶段 | 动作 | 理由 |
|---|---|---|
| 衰退 | **大胆买**，买什么不重要 | 经济、流动性、估值的三重底部，向下空间小于向上空间；历史回头看这是胜率最高的买点 |
| 过热 | **看情绪准备离场** | 泡沫通常很快被刺破；身边朋友都在讨论股票时就是离场信号 |
| 复苏 / 下行 | **重选股，轻择时** | 行情不雨露均沾，风格与行业轮动快；这两个阶段占总时间的大部分 |
| 全阶段 | 择时是必须的 | A 股牛短熊长：牛市平均 9 个月、熊市平均 18 个月；大盘 4 次大牛市平均 7–8 年一次；回撤超 20% 十多次、超 40% 八次 |

> 「衰退阶段买什么并不重要」只在**指数层面**成立。原文紧接着说「好资产、好价格，缺一不可」，且「不懂的不做，只买自己懂的资产」——这是两个不同层次的话，不要混成一句。

### 3.3 硬约束：择时 ≠ 预测

原文明确：**永远无法做到最低位精准买入，也没办法一买就涨**。做的是**大周期择时**（判断周期阶段与轮动规律），不是点位预测。判断周期不容易，这才是需要研究时间的地方。

## 4. 极端情形

1. **指标不同步**：GDP 是季度数据（滞后 1–2 个月），成交额是日频，估值日频。用月度 GDP 判定日频阶段会造成系统性错位，必须按发布日期对齐（GDP 只有未来函数就退化成同步指标）。
2. **政策日尖峰**：成交额在政策日暴增会伪造「人和转强」；用 20 日均值而非单日。
3. **注册制导致绝对家数/成交额漂移**：成交额是金额口径，比家数稳定，但仍受全市场扩容与市值中枢上移影响，必须用分位。
4. **「混沌」档不能忽略**：现实里三因不同步是常态，硬套四阶段会产生频繁切换的错误信号。必须设**最小驻留时间**（如阶段至少持续 1 个季度才切换）。
5. **通缩/通胀周期切换点**：美元加息顶点 = 各国资产被收割的底部区间；降息开启 = 资产修复窗口。见 [[通胀周期的投资核心思路（上）]]，这条是外部节奏，与国内三因不同源，**必须作为独立维度**。
6. **2021 年的反例**：经济仍强、成交额从 7 月开始下行 → 判定「下行阶段」，但中证 500/1000 全年仍涨 15.58%/20.52%。**阶段判定不等于个股/风格不赚钱**。
7. **政策底 ≠ 市场底**：复苏阶段「没有坚定的主线」，轮动极快，这是最容易亏钱也最容易误判的阶段。

## 5. 数据与实现

- GDP 同比：国家统计局季度数据；**必须用公布日而非统计期对齐**（国家数据有多个修订版本）。
- 成交额：沪深两市合计日成交额；注意北交所口径是否计入，保持一致。
- 估值分位：宽基指数 PE/PB 的历史分位（10 年窗口）；**绝对估值档位（60%/80%）已经是分位口径，直接可用**。
- 阶段切换规则：滞回（hysteresis）——进入下一阶段需要指标突破阈值 + 连续 N 期确认，避免在阈值附近来回抖。

### 已知的回测教训（来自本库 P0 批次）

[[P0-回测总览]] 的一条贯穿性发现：**凡是依赖绝对数值的口径，全部漂移失效。** U03 用绝对均线、U07 用绝对家数，全部不通过；U08 用「相对自己过去半年的偏离」则通过。

因此本指标的三条代理变量**全部必须用分位或自身历史的变化率**，不得使用任何跨时代固定的绝对值（例如「成交额破万亿」这种说法在 2015 年和 2024 年完全不是一回事）。

## 6. 回测与验证

对应看板三条互相纠缠的假设：

| 编号 | 假设 | 依赖 |
|---|---|---|
| U12 | 「GDP 增速下行 + 成交额萎缩 + 宽基估值分位 <20%」标记衰退阶段后，未来 6–12 个月沪深 300 收益显著高于全年均值，且下行空间小于上行空间 | 月度重采样做阶段划分 |
| U13 | 宽基估值分位 >80% 后，未来 6 个月收益为负的概率显著高于 50%；>60% 时未来 3 个月转负概率上升 | 估值分位 + 指数日线 |
| U14 | 成交额处于历史 90% 分位（情绪高位）建仓，未来 12 个月持有收益显著低于 10% 分位（情绪冰点）建仓 | 成交额分位 + 指数日线 |

方法要求：

1. 阶段划分必须在**样本内**定规则，样本外只应用，不允许看到结果后改阈值。
2. U12 的三个条件是「同时成立」还是「任一成立」必须先固定，不能试了再挑。
3. 每段阶段至少统计 20 个样本（不足记「样本不足」）。
4. 基准：与买入持有沪深 300 比超额；同时报绝对收益和相对中位股收益（[[P0-回测总览]] 显示 2022–2026 两者可能符号相反）。
5. 结论只写「通过 / 不通过 / 样本不足」。

### 待验证的边界

1. **三因是否真的正交**：成交额与估值分位高度同源（都是价格/交易行为的产物），可能不构成 3 个独立维度，需测相关性。
2. **阶段切换的滞后成本**：月频判定 + 最小驻留期会显著拉长信号滞后，扣掉滞后后还有没有超额，未测。
3. **「混沌」档怎么处理**：目前没有量化定义，是最大的落地障碍。
4. **外部货币周期与国内周期的交互**：通胀周期素材提出的「美元降息开启 = 资产修复」是独立维度，未与本指标合并。
