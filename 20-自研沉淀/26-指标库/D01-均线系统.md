# D01 均线系统

> 来源：[[波段交易]]（5/10 日线低吸、跌破 20 日线止损、月/周/日三周期向上）、[[下有界限，上不封顶，概率与盈亏比]]（不破 10 日线持有）、[[交易心得]]（5/20/60 双均线、看大做小、双周期共振）。
> 回答的问题：**趋势在不在？回踩到哪里买？跌破哪里认错？**

## 1. 公式

```text
MA_n(t) = (C_t + C_{t−1} + … + C_{t−n+1}) / n
EMA_n(t) = α·C_t + (1−α)·EMA_n(t−1)，α = 2/(n+1)
```

常用周期：5（一周）、10（两周）、20（一月）、60（一季）。

派生：

```text
多头排列      = MA5 > MA10 > MA20（强趋势可加 MA60）
MA20斜率10日  = (MA20_t − MA20_{t−10}) / MA20_{t−10} × 100
收盘乖离      = (C − MA20) / MA20 × 100
均线距离      = (MA5 − MA20) / MA20 × 100
```

## 2. 趋势评分（0–4）

| 条件 | 得分 |
|---|---:|
| 收盘价 > MA20 | +1 |
| MA5 > MA10 > MA20 | +1 |
| MA20 的 10 日斜率 > 0 | +1 |
| 收盘价 > MA60 且 MA60 斜率 > 0 | +1 |

| 总分 | 状态 | 动作 |
|---|---|---|
| 4 | 强趋势 | 可正常参与，回踩买 |
| 3 | 上升趋势 | 可参与，仓位正常 |
| 2 | 混合/震荡 | 降仓，只做区间 |
| ≤1 | 下降/无趋势 | 不做多，等结构修复 |

## 3. 买卖规则

### 3.1 选股

- 日线：`C > MA20` 且 `MA20` 斜率 > 0；波段要求周线、月线同向（[[波段交易]]）。
- 不买「股价在 20 日线下方、均线向下」的左侧下跌票；[[@Fioona交易模式的简单分享]] 明确不做左侧抄底。

### 3.2 买点

| 买点 | 条件 | 风险 |
|---|---|---|
| 回踩 MA5/MA10 | 趋势向上，回踩缩量，企稳后重新向上 | 追高者容易买在反抽末端 |
| 回踩 MA20 | 趋势较强，20 日线向上，回踩不破 | 跌破则趋势可能变了 |
| 突破 | 放量突破前高/平台，回踩不破 | 假突破 |

> [[波段交易]]：强势股回踩 5 日线被快速拉起，是低吸点；冲高远离 5 日线且放大量，是高抛点。

### 3.3 止损/持盈

| 周期 | 止损参考 | 说明 |
|---|---|---|
| 短线 | 收盘跌破 MA10 | [[下有界限，上不封顶，概率与盈亏比]] 的持盈线 |
| 波段 | 收盘跌破 MA20 | [[波段交易]] 的止损线 |
| 趋势 | 跌破 MA60 或前低 | 更大级别走坏 |

**缓冲**：`收盘 < MA20 × (1 − 0.5%～1%)` 或 `收盘 < MA20 − 0.5×ATR14` 才算有效跌破，避免一天插针被洗。盘中跌破不算，收盘确认。

## 4. 极端情形

1. **跳空/一字板**：均线是滞后线，跳空跌破时价格已远离；止损用「收盘价 + 缓冲」，但实际成交可能在更差位置。跌停板可能卖不出。
2. **震荡市反复打脸**：均线在横盘里频繁金叉死叉；[[交易心得]] 提醒「市场大量时间处在震荡，不能只用趋势思维」。震荡期降低仓位或改用区间规则。
3. **参数漂移**：5/10/20/60 是常用值，不是圣杯；不同标的波动率不同，需按 ATR 归一化或做参数敏感性。
4. **复权问题**：除权除息会让均线跳变；必须用同一套复权数据（前复权/后复权固定一种），回测与实盘一致。
5. **流动性差的小票**：均线容易被少量成交拉动；加成交额/换手率过滤。
6. **2024-02 小微盘危机**：均线止损在连续跌停中失效，滑点极大；仓位控制比止损线更重要。
7. **多周期冲突**：日线向上、周线向下时，均线信号相反；按 [[D03-多周期权责]] 事先定好谁有否决权。

## 5. 数据与实现

- 复权：前复权适合看图，后复权适合回测；固定一种，别混用。
- 均线：`MA(C,N)`；通达信/同花顺一致；注意 `MA` 是简单均线，`EMA` 是指数均线。
- ATR：`TR=max(H−L, |H−前收|, |L−前收|)`；`ATR14=MA(TR,14)`。
- 频率：日线为主；周线/月线用周/月收盘。

## 6. 回测与验证

- 假设（[[待验证策略看板]] U03）：月/周/日三周期同向 + 回踩 5/10 日线低吸 + 跌破 20 日线止损，能捕获波段中段且回撤可控。
- 方法：固定规则逐日回放；信号收盘确认，次日开盘/收盘成交；统计胜率、盈亏比、期望、MDD、最大连亏。
- 参数：5/10/20/60 vs 10/20/60 vs 5/20/60；缓冲 0%、0.5%、1%；分组看参数敏感性。
- 成本：佣金、印花税卖出 0.05%、滑点；一字板/跌停不可成交样本剔除。
- 分段：2015、2018、2021、2024-02、2024-09；至少 2 年样本外。

### 回测结论（2026-10-24）：不通过

报告：[[BT-U03-波段均线系统]]｜看板：[[待验证策略看板]] U03

| 检验项 | 结果 |
|---|---|
| 相对中位股超额 | 5/10/20/60 日 +0.52% / +0.81% / +1.59% / +3.48%，t = +20.2 / +22.8 / +32.1 / +43.2 |
| 绝对收益 | 20 日样本内 −1.98%，样本外 +1.15% |
| 组合表现 | CAGR −12%～−40%，MDD 43%–89%；基准 HS300 CAGR −0.01% / MDD 25.1% |
| 结论 | **不通过**：公式与相对排序有效，但「回踩买 + 破 MA20 止损」这套买卖规则扣成本后为负 |

已证伪：§3.3 的 MA10 / MA20 止损与 MA20 出场；§3.1 的多周期同向过滤（样本内 20 日 −1.31%，t=−12.5）。
未证伪、保留：§1 公式、§2 趋势评分（可作**横截面排序因子**，不作择时入场）。

替代用法见 [[P0-回测总览]] 的下一步队列。
