# D02 趋势结构与123法则

> 来源：[[123交易法则]]（道氏理论 / 《专业投机原理》）。
> 回答的问题：**已有趋势是不是要变了？** 它不预测起点，只判断「延续」还是「反转」。

## 1. 结构定义

### 1.1 摆动高低点

```text
Pivot High(t,k): H_t ≥ max(H_{t−k}…H_{t−1}) 且 H_t > max(H_{t+1}…H_{t+k})
Pivot Low(t,k):  L_t ≤ min(L_{t−k}…L_{t−1}) 且 L_t < min(L_{t+1}…L_{t+k})
```

- `k` 常用 2–5；`k` 越大，结构越稳、确认越晚。
- **Pivot 在 `t+k` 根后才确认**；实盘/回测不能在 `t` 当天就知道，否则是未来函数。

### 1.2 上升趋势

```text
最近两个 Pivot High：PH2 > PH1（高点抬高）
最近两个 Pivot Low： PL2 > PL1（低点抬高）
上升趋势线：连接 PL1、PL2；t 时刻线值 = PL2 + slope×(t − t2)
```

下降趋势反过来：高点降低、低点降低，趋势线连接两个降低的高点。

## 2. 123 三步

以「上升转下降」为例：

| 步骤 | 条件 | 含义 |
|---|---|---|
| 1 破线 | 收盘价跌破上升趋势线 − 缓冲 | 上涨节奏首次破坏，可能只是回调 |
| 2 测试失败 | 破线后反弹，未创新高（反弹高点 < PH2） | 恢复上涨失败 |
| 3 确认 | 收盘价跌破「关键低点」− 缓冲 | 反转证据强化 |

```text
关键低点 = PH2 与反弹高点之间那段行情的最低点
缓冲     = 0.5 × ATR14（或 0.5%–1%）
有效窗口 = 步骤1 到步骤3 在 20–60 根 K 线内
```

下降转上升反向对应：突破下降趋势线 → 回落不创新低 → 突破关键前高。

### 2.1 判定表

| 信号 | 状态 | 动作倾向 |
|---|---|---|
| 只有步骤 1 | 警告 | 减仓/观察，不反手 |
| 1 + 2 | 高概率反转 | 退出多单，等确认 |
| 1 + 2 + 3 | 反转确认 | 清仓/考虑反向 |
| 步骤 2 创新高 | 123 失败，趋势延续 | 恢复原方向 |
| 只有步骤 3、没有步骤 2 | 不是标准 123（常见 V 型） | 不硬套，用其他规则 |
| 三步超过 60 根才完成 | 信号过期 | 重新画结构 |

## 3. 关键细节

1. **收盘价确认**：[[123交易法则]] 明确「影线碰趋势线不算破，需收盘价确认」。
2. **趋势线锚点固定**：连接最近两个抬高的低点；不要事后挑一条「刚好被碰到」的线。
3. **步骤顺序不能乱**：先破线、再测试失败、再破关键低点；顺序错了不算 123。
4. **三步只是证据增加**，不是必然反转；可能反复，需结合量价/均线。
5. **急转时确认偏晚**：V 型反转可能没有步骤 2；123 会错过第一段。

## 4. 极端情形

1. **V 型反转/政策底**：2015 救市、2024-09 政策转向，价格快速拉起，没有「反抽不创新高」；123 不适用。
2. **跳空/一字板**：步骤 3 可能以跳空方式完成，确认时已跌很多；止损/反手成本高，跌停可能无法成交。
3. **趋势线主观性**：不同人画线不同；必须用算法固定锚点、缓冲和确认价，否则无法回测。
4. **假突破**：跌破趋势线后迅速收回；缓冲和收盘确认能减少假信号，但会增加滞后。
5. **多周期冲突**：日线 123 与周线趋势相反时，按 [[D03-多周期权责]] 事先定权责。
6. **小样本/流动性差**：Pivot 稀少、价格跳变，结构不可靠；加流动性过滤。
7. **指数 vs 个股**：指数 123 更稳，个股易被单笔大单扭曲；个股需结合板块。

## 5. 数据与实现

- 数据：日线/周线 OHLC，固定复权。
- 算法顺序：先算 Pivot（右 k 根确认）→ 识别高低点抬高/降低 → 连接最近两个同向 Pivot → 逐日判断收盘是否破线 → 记录步骤 1/2/3 与时间窗。
- 不能用「未来已知的 Pivot」回填当时信号；信号时间戳记为确认日。
- 可视化：在图上标注三步与关键低点，方便人工复核。

## 6. 回测与验证

- 假设（[[待验证策略看板]] U01）：上升趋势中「破线 → 反抽不创新高 → 跌破关键低点」三步全部出现后，未来 N 日反转概率显著高于随机。
- 参数：`k=2/3/5`；缓冲 `0/0.5 ATR/1%`；窗口 `20/40/60`；分别跑，报告敏感性。
- 方法：逐日回放，信号确认后次日开盘执行；统计未来 10/20/60 日收益、胜率、盈亏比、MDD；与「同期随机入场」对照。
- 成本：佣金、印花税、滑点；跳空/跌停不可成交样本剔除。
- 分段：2015、2018、2021、2024-02、2024-09；至少 2 年样本外。
- 结论只写「通过/不通过/样本不足」。
