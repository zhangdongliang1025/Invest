# D04 价格行为与量价承接

> 来源：[[波段交易]]（均线 + 情绪、放量突破/跌破）、[[@Fioona交易模式的简单分享]]（趋势→位置→形态→量能→突破确认、N 字、高位放量分歧兑现）、[[交易心得]]（量价、承接、持续性）。
> 回答的问题：**这个位置、这个形态、这个量，值不值得下手？**

## 1. K 线形态的可计算定义

先定义单根 K 线：

```text
实体      = |C − O|
上影      = H − max(C,O)
下影      = min(C,O) − L
全幅      = H − L
收盘位置  = (C − L) / (H − L)
```

| 形态 | 判定 |
|---|---|
| 看涨吞没 | 今日阳线，实体完全包住昨日阴线实体；`C_t ≥ O_{t−1}` 且 `O_t ≤ C_{t−1}` |
| 看跌吞没 | 今日阴线，实体完全包住昨日阳线实体 |
| 看涨 Pin Bar | 下影 ≥ 2×实体；收盘位置 ≥ 0.67；实体较小 |
| 看跌 Pin Bar | 上影 ≥ 2×实体；收盘位置 ≤ 0.33 |
| 双顶 M | 两个高点差 ≤ 2%（或 0.5 ATR）；跌破两高点之间的低点（颈线）确认 |
| 双底 W | 两个低点差 ≤ 2%；突破颈线确认 |
| 头肩顶 | 三峰，中间最高；两低点连成颈线；收盘跌破颈线确认 |
| N 字 | 上涨 A→B；回调 B→C 且 C 不破 A 低；放量突破 B 高点 |

> 形态是「区域」不是「精确线」；用 2% 或 0.5 ATR 的容差，避免差一分钱就不算。

## 2. 量价公式

```text
量比（收盘）= VOL_t / MA5(VOL)
量比（盘中）= (VOL_t / 已开盘分钟数) / (MA5(VOL) / 240)
VR          = VOL_t / MA5(VOL)
换手率      = VOL_t / 自由流通股本 × 100%
```

| 量比 | 状态 |
|---|---|
| >2.0 | 明显放量 |
| 1.5–2.0 | 放量 |
| 0.7–1.5 | 正常 |
| <0.7 | 缩量 |

## 3. 支撑/阻力与突破确认

**位置来源**：

- 前高/前低、摆动高低点（[[D02-趋势结构与123法则]]）；
- 成交密集区/高成交量节点；
- 整数关口；
- 缺口边缘；
- 均线（[[D01-均线系统]]）。

**有效突破**：

```text
收盘 > 阻力 + 0.5×ATR14
且 量比 > 1.5
且 回踩 1–3 根不破阻力
```

**有效跌破**同理反向。只满足价格、不满足量，叫「无量突破」，持续性存疑。

## 4. 判断标准

| 量价形态 | 解读 | 动作倾向 |
|---|---|---|
| 放量突破 + 回踩不破 | 承接确认 | 可买/加 |
| 放量突破 + 次日跌回 | 假突破 | 不追，已买则止损 |
| 缩量回踩 + 企稳 | 抛压小 | 低风险买点 |
| 放量滞涨/长上影 | 上方抛压/派发 | 减仓 |
| 放量跌破支撑 | 趋势破坏 | 退出 |
| 缩量跌破支撑 | 可能洗盘，也可能无人接 | 等收回，不急着抄 |
| 高位放量反复开板 | 分歧兑现（[[@Fioona交易模式的简单分享]]） | 兑现 |
| 低位缩量横盘后放量 | 可能启动 | 等突破确认 |

## 5. 极端情形

1. **一字板/涨跌停**：没有有效成交量，量价形态失效；不能用「缩量涨停」判断强弱，也不能假设能买到。
2. **跳空**：形态被切断；缺口本身成为支撑/阻力；止损可能跳空穿越。
3. **流动性空洞**：小票几笔大单就能画出长影/放量；用成交额中位数、盘口深度过滤。
4. **人为做量**：对倒、尾盘拉升、大宗交易会污染量比；看连续 3–5 日的量价一致性。
5. **除权除息**：不复权数据会出现假跳空/假吞没；固定复权口径。
6. **指数调仓/ETF 申赎**：成分股在调仓日放量，不是技术信号。
7. **T+1**：当天买入不能当天止损；日内突破买入遇到尾盘跳水，只能次日处理。
8. **2024-02 流动性危机**：支撑位在连续跌停下失效，量价形态无法反映流动性风险；仓位比形态重要。

## 6. 回测与验证

- 假设（[[待验证策略看板]] U03/U02）：放量突破 + 回踩不破的买点，未来 5/10/20 日收益优于无量突破。
- 方法：把形态写成算法（容差、量比、ATR 缓冲固定），逐日回放；信号收盘确认，次日开盘执行。
- 统计：胜率、盈亏比、期望、MDD；按「有量/无量」「回踩/不回踩」分组。
- 成本：佣金、印花税、滑点；一字板/跌停不可成交样本剔除。
- 分段：2015、2018、2021、2024-02、2024-09；至少 2 年样本外。
- 注意：形态参数（2%、0.5 ATR、量比 1.5）都要做敏感性，避免拟合。
