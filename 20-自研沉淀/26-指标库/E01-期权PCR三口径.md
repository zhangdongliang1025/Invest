# E01 期权 PCR 三口径

> 来源：[[期权PCR与大盘关系]]。
> 回答的问题：**机构在为下跌买多贵的保险？** PCR 是「认沽/认购」的相对活跃度，不是做空证据。

## 1. 三种口径

```text
成交量PCR = Σ认沽成交张数 / Σ认购成交张数
持仓量PCR = Σ认沽未平仓合约 / Σ认购未平仓合约
成交额PCR = Σ认沽权利金成交额 / Σ认购权利金成交额
```

| 口径 | 频率 | 反映 | 注意 |
|---|---|---|---|
| 成交量 PCR | 日 | 短期情绪、当日避险冲动 | 受当日到期/移仓影响 |
| 持仓量 PCR | 日 | 中长期对冲仓位 | 收盘后更新，趋势更稳 |
| 成交额 PCR | 日 | 真实资金投入、保险成本 | 认沽下跌时升值，会放大 |

**口径必须固定**：同一标的、同一到期月（近月）、同一数据源；宽基与成长分开算，不能把 50ETF、300ETF、科创 50、创业板混成一个数。

## 2. 判断标准

### 2.1 绝对阈值（原文）

| 指标 | 阈值 | 含义 |
|---|---|---|
| 成交量 PCR | >1.5 | 极端恐慌区 |
| 成交量 PCR | <0.7 | 乐观/认购活跃 |
| 沪深 300 PCR | >1.2 | 警惕系统性回调 |
| 成长（创业板/科创 50）PCR | >1.0 | 注意小票/成长波动 |
| 极端恐慌 | PCR>1.8 且 IV>30% | 可能「恐慌耗尽」，但需现货企稳 |
| 极端乐观 | PCR<0.6 且 IV<15% | 乐观陷阱，警惕突发踩踏 |

### 2.2 相对阈值（更稳）

```text
成交量PCR偏离 = 当前值 − 近20日均值      // +0.5 以上显著
持仓量PCR偏离 = 当前值 − 近20日均值      // +0.3 以上显著
PCR分位       = percentile_rank(PCR, 1年/3年)
```

### 2.3 组合判断

| 组合 | 状态 | 动作倾向 |
|---|---|---|
| PCR>1.8 + IV>30% | 极端恐慌 | 不追空；等 IV 回落 + 现货企稳 |
| PCR 1.2–1.8 | 风险升温 | 降仓/收紧 |
| PCR 0.8–1.2 | 中性 | 按个股规则 |
| PCR<0.6 + IV<15% | 过度乐观 | 买保护/降仓 |
| 成交量 PCR 降、持仓量 PCR 升 | 短期情绪缓和、中期对冲增加 | 警惕，不追高 |
| 成交额 PCR 明显高于成交量 PCR | 保险变贵（IV 上升） | 风险溢价上升 |

## 3. 案例读法（2026-10-14 原文数据）

| 标的 | 成交量 PCR | 前值 | 解读 |
|---|---:|---:|---|
| 上证 50 | 0.85 | 0.74 | 避险升温但未极端 |
| 沪深 300 | 1.01 | 持平 | 整体可控 |
| 科创 50 | 0.99 | 0.69 | 成长避险需求明显上升 |
| 创业板 | 0.95 | 0.60 | 成长避险升温 |
| 合计 | ≈0.96 | — | 认沽未全面压倒认购 |

认沽成交额：创业板 6.9 亿、沪深 300 2.1 亿、上证 50 0.9 亿；合计 14.5 亿是**双边统计**，不等于「机构花 14.5 亿做空」。结论是「风险保护成本上升」，不是「巨额空单」。

## 4. 极端情形

1. **到期周/移仓**：近月到期前后，成交量 PCR 剧烈波动；改用次月或滚动 5 日均值。
2. **长假/事件前**：买保护需求集中，PCR 会提前升高；事件落地后快速回落（IV crush）。
3. **标的差异**：科创 50、创业板 IV 天然高，PCR 阈值不能和上证 50 共用；[[期权PCR与大盘关系]] 明确要分宽基/成长。
4. **做市商对冲**：机构买认沽 → 做市商卖认沽 → 卖期货/ETF 对冲 → 越跌越卖，放大波动；PCR 高不代表「有人恶意做空」。
5. **双边统计**：期权成交有买有卖，成交量/成交额是双边；不能直接读成净空头。
6. **数据源差异**：Wind、同花顺 iFinD、东财对「成交量/持仓量」统计口径可能不同；同一研究必须用同一源。
7. **低流动性合约**：深度虚值认沽几笔大单就能拉高 PCR；加成交额/持仓量过滤。

## 5. 数据与实现

- 标的：510050（50ETF）、510300（300ETF）、588080/588000（科创 50）、159915（创业板）。
- 字段：认沽/认购成交量、持仓量、成交额；近月合约；同一到期日。
- 频率：日频，收盘后。
- 工具：Wind、同花顺 iFinD、东方财富期权链；免费数据可能延迟。

## 6. 回测与验证

- 假设（[[待验证策略看板]] U10）：沪深 300 成交量 PCR>1.2 且 IV>25% 后，未来 5 日指数波动与回撤显著放大。
- 方法：按 PCR 分位分 5 组，统计未来 1/5/10 日指数收益、波动、最大回撤；PCR 与 IV 双条件分组。
- 时点：收盘信号，次日开盘/收盘；期权数据用当日收盘。
- 分段：2015–2018、2019–2022、2023–2026；至少 2 年样本外；不同标的分别跑。
- 注意：PCR 是同步/略领先的风险指标，不是精确抄底工具；极端恐慌后的反弹统计要扣成本和滑点。
