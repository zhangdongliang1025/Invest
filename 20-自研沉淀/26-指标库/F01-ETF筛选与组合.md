# F01 ETF 筛选与组合

> 来源：[[行业ETF基金知识]]、[[行业ETF池]]。
> 回答的问题：**同一个行业，选哪只 ETF？几只 ETF 怎么组合才不变成同一个赌注？**

## 1. 筛选公式

```text
跟踪误差 TE = std(r_ETF − r_index) × √252          // 日收益，年化
跟踪差异 TD = (累计ETF净值收益 − 累计指数收益) / 年数
折溢价     = (二级市场价格 − 基金净值) / 基金净值 × 100%
日均成交额 = 近20日成交额均值
```

| 指标 | 建议门槛 | 说明 |
|---|---|---|
| 基金规模 | ≥2 亿元 | 太小有清盘/流动性风险 |
| 日均成交额 | ≥1000 万元 | 买卖冲击成本可控 |
| 跟踪误差 | ≤2%/年 | 越小越好；同类比较 |
| 综合费率 | 0.2%–0.6%/年 | 管理费+托管费，长期累积 |
| 折溢价 | 绝对值为小 | >2% 不追；折价要查原因 |
| 前十大权重 | 看集中度 | 太高=行业更纯粹也更集中 |
| 指数编制 | 市值/等权/策略 | 决定风险暴露 |

## 2. 组合公式

```text
相关系数 ρ_ij = cov(r_i, r_j) / (σ_i × σ_j)       // 60/120日日收益
组合波动 σ_p = sqrt(ΣΣ w_i w_j ρ_ij σ_i σ_j)
再平衡触发   = |w_i − 目标w_i| > 5%，或每季度一次
```

| 约束 | 建议 |
|---|---|
| 行业数量 | 3–5 个，逻辑不同、相关性低 |
| 单只上限 | 30%–40% |
| 相关性 | 最好 <0.7；>0.8 视为重复暴露 |
| 再平衡 | 偏离 ±5% 或季度 |
| 建仓方式 | 分批/定投，不一次打满 |
| 现金/债券 | 保留一部分，用于极端行情 |

## 3. 判断标准

| 情况 | 判断 | 动作 |
|---|---|---|
| 规模 <2 亿 或 日均成交 <1000 万 | 流动性不足 | 剔除 |
| 跟踪误差 >2% | 复制能力差 | 剔除/换同类 |
| 费率 >0.6% | 长期成本高 | 优先低成本 |
| 溢价 >2% | 买贵了 | 不追，等回落 |
| 折价 >2% 且流动性好 | 可能有机会 | 查原因（停牌/申赎限制） |
| 两只 ETF 相关性 >0.8 | 重复暴露 | 只留一只 |
| 前十大 >70% | 集中度高 | 当行业主题仓，控制权重 |
| 规模持续 <5000 万 | 清盘风险 | 回避 |

## 4. 极端情形

1. **流动性枯竭**：极端行情下 ETF 成交额骤降、买卖价差扩大；折溢价可能失真，止损成本高。
2. **溢价/折价陷阱**：QDII、跨境 ETF 因额度/时差常年溢价；高溢价买入可能承担额外损失。
3. **清盘/合并**：小规模 ETF 可能清盘；临近清盘时流动性更差。
4. **指数编制变化**：成分调整、权重规则变化会改变 ETF 风险暴露；读招募说明书。
5. **危机相关性→1**：平时低相关的行业，在系统性下跌中一起跌；分散不能消除 beta。
6. **行业主题集中**：单一行业 ETF 波动远高于宽基；[[行业ETF基金知识]] 明确「不要把所有资金押在单一行业」。
7. **跟踪误差在极端行情放大**：停牌股、涨跌停、申赎限制会让 ETF 偏离指数；用 TE 和折溢价一起看。
8. **分红/拆分**：份额变化不等于资金流；用复权净值算收益。

## 5. 数据与实现

- 规模/份额：基金季报、交易所、天天基金。
- 跟踪误差：日净值 vs 指数日收益，年化；至少 1 年，最好 3 年。
- 费率：基金合同/招募说明书；管理费+托管费，注意销售服务费。
- 折溢价：交易所 IOPV 与二级市场价格；盘中实时，收盘后复核。
- 相关性：用复权净值，60/120 日滚动；行业 ETF 上市不足 1 年时样本不足。
- 标的池：[[行业ETF池]] 的代码需定期核对，避免代码/名称变更。

## 6. 回测与验证

- 假设（[[待验证策略看板]] U11）：按「政策 + 景气 + 估值」筛选 3–5 个低相关行业 ETF 并定期再平衡，长期优于单一行业。
- 方法：组合回测 vs 单行业 vs 沪深 300；统计 CAGR、波动、MDD、Calmar、换手率。
- 时点：ETF 用可交易价格/净值；成分与费率按当时；避免用后来才上市的 ETF 回测过去。
- 成本：佣金、价差、折溢价；ETF 免印花税但仍有成本。
- 分段：2018–2021、2022–2024、2024–2026；至少 2 年样本外。
- 注意：低相关是历史统计，危机时会上升；组合层面要做压力测试。
