# G01 胜率、盈亏比与回撤

> 来源：[[下有界限，上不封顶，概率与盈亏比]]、[[@Fioona交易模式的简单分享]]、[[@Fioona· 9月28日市场唯一的捷径--纪律]]。
> 回答的问题：**这套方法长期有没有正期望？最坏能坏到什么程度？** 这是策略能否活下来的体检表。

## 1. 公式

```text
胜率 p        = 盈利笔数 / 总笔数
盈亏比 R      = 平均盈利 / 平均亏损
单笔期望 E    = p × 平均盈利 − (1−p) × 平均亏损
以 R 为单位   E_R = p × R − (1−p)
保本胜率 p*   = 1 / (1 + R)
盈利因子 PF   = 总盈利 / |总亏损| = [p/(1−p)] × R
最大回撤 MDD  = max_t (1 − Equity_t / max_{s≤t} Equity_s)
Calmar        = 年化收益 / MDD
```

## 2. 保本胜率表

| 盈亏比 R | 保本胜率 p* |
|---:|---:|
| 1.0 | 50.0% |
| 1.5 | 40.0% |
| 2.0 | 33.3% |
| 3.0 | 25.0% |
| 4.0 | 20.0% |

> 这就是「盈亏比至少 1:1.5，十笔亏五赢五也能赚」的数学来源：R=1.5 时，保本只需 40% 胜率。

## 3. 判断标准

| 指标 | 参考阈值 | 说明 |
|---|---|---|
| 胜率 p | >40% | 低于 40% 时，R 必须更高 |
| 盈亏比 R | >1.5–2 | 低于 1.5 需要很高胜率 |
| 单笔期望 E_R | >0.2R | 太薄会被成本吃掉 |
| 盈利因子 PF | >1.5 | <1.2 视为弱 |
| 最大回撤 MDD | <10% | 超过则降仓/改规则 |
| 样本量 | ≥50 笔 | 少于 30 笔只算样本不足 |
| 回测长度 | ≥3 年 | 覆盖牛/熊/震荡 |
| 模拟盘 | 1–3 个月 | 看执行力，不只看收益 |

### 组合诊断

| 情况 | 判断 |
|---|---|
| `E_R>0.2` + `R>1.5` + `MDD<10%` + 50 笔 | 候选策略，可小仓验证 |
| `E_R>0` 但 `MDD>20%` | 期望为正但活不下来；降仓或改止损 |
| `p<30%` 且 `R<2` | 脆弱，连续亏损容易失控 |
| `PF<1.2` | 成本/滑点一扣就转负 |
| 最大连亏超过样本内预期 | 检查是否 regime 变了 |

## 4. 极端情形

1. **小样本幻觉**：10 笔 8 胜不代表 80% 胜率；至少 50 笔，最好 100 笔。
2. **肥尾**：平均亏损会低估极端亏损；看最大单笔亏损、最大连亏、95% 分位亏损，不只看均值。
3. **幸存者偏差**：只统计活下来的策略/股票；回测要包含退市、失败样本。
4. **过拟合**：参数调得越细，样本外越差；留 2 年样本外，参数不超过 2–3 个。
5. **成本吞噬**：短线高胜率策略对佣金/印花税/滑点极敏感；回测必须扣双边成本。
6. **杠杆放大回撤**：MDD 10% 在 2 倍杠杆下变 20%+，可能触发强平；先定风险，再谈收益。
7. **Regime 变化**：2015、2018、2024-02 的分布不同；分年统计，不只看全样本。
8. **心理执行**：回测胜率 60%，实盘可能因为不敢下单/提前止盈变成 40%；模拟盘验证执行力。

## 5. 数据与实现

- 交易记录：日期、标的、方向、入场、止损、出场、仓位、盈亏、是否按计划。
- 统计脚本：按策略/市场环境/标的类型分组；计算 p、R、E、PF、MDD、最大连亏。
- 权益曲线：按市值逐日 mark-to-market，不要只按已实现盈亏。
- 成本：佣金、印花税卖出 0.05%、滑点；ETF 免印花税但仍扣佣金/价差。

## 6. 回测与验证

- 流程：3 年回测 → 50+ 笔统计 → 1–3 个月模拟盘 → 小资金实盘 → 逐步加仓。
- 样本外：前 60% 定规则，后 40% 验证；不许在全样本上反复调参。
- 分组：按牛/熊/震荡、按板块、按买入方式（低吸/突破/追涨）分别统计，找出「重复赚钱的那一类」。
- 结论：只写「通过/不通过/样本不足」；不通过要写清是逻辑不成立、成本吞噬还是样本不足。
- 更新：每 50 笔复盘一次；MDD 超限先降仓，不改规则救急。

### 回测结论（2026-10-24）：数学部分有效，框架本身不是 alpha

报告：[[BT-U06-盈亏比与止损]]｜看板：[[待验证策略看板]] U06

- §2 保本胜率表**算术无误**，且被样本验证：R=2 时实测 R 胜率 37.2% > 保本线 33.3%。
- 但同一套规则下，**随机入场的对照组在每个指标上都优于信号入场**：样本外随机 +0.72%（PF 1.166）vs 信号 +0.23%（PF 1.043）。
- 正 R 被两类退出方式漏掉：20.5% 的交易靠 20 日时间止损出场，5.3% 靠跳空止损出场。
- 结论：盈亏比与止损负责**控制亏损分布、提高存活概率**，不产生超额收益。本页阈值保留为风控口径，不能当选股信号用。
