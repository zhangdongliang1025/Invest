# G02 仓位与单笔风险预算

> 来源：[[下有界限，上不封顶，概率与盈亏比]]（单票 30%–40%、严格止损）、[[交易心得]]（仓位过重会扭曲判断）、[[金融心理学]]（损失厌恶）。
> 回答的问题：**这一笔最多亏多少？对应买多少股？** 先定亏损，再定仓位，不反过来。

## 1. 公式

```text
单笔风险金额 = 权益 × 单笔风险比例 r
每股风险     = 入场价 − 止损价
股数         = 单笔风险金额 / 每股风险
仓位市值     = 股数 × 入场价
仓位比例     = 仓位市值 / 权益 = r / 止损距离%
组合热力     = Σ 所有持仓的未实现风险 / 权益
```

### 例

| 项目 | 数值 |
|---|---:|
| 权益 | 1,000,000 |
| 单笔风险 r | 1% → 10,000 |
| 入场价 | 10.00 |
| 止损价 | 9.20 |
| 止损距离 | 8% |
| 股数 | 10,000 / 0.80 = 12,500 股 |
| 仓位市值 | 125,000 |
| 仓位比例 | 12.5% |

## 2. 判断标准

| 参数 | 保守 | 标准 | 激进 | 不建议 |
|---|---:|---:|---:|---:|
| 单笔风险 r | 0.5%–1% | 1%–2% | 2%–3% | >3% |
| 单票仓位上限 | 10%–15% | 20%–30% | 30%–40% | >40% |
| 组合热力 | <3% | 4%–6% | 6%–8% | >8% |
| 最大回撤容忍 | 5% | 10% | 15% | >20% |

> [[下有界限，上不封顶，概率与盈亏比]] 说「单票 30%–40%」，那是**仓位上限**，不是单笔风险；两个约束同时用，取更小的那个。

## 3. 止损距离与仓位的关系

| 止损距离 | r=1% 时的仓位 | 说明 |
|---:|---:|---|
| 3% | 33.3% | 容易被噪声打掉 |
| 5% | 20.0% | 短线常用 |
| 8% | 12.5% | 波段常用 |
| 10% | 10.0% | 趋势/大票 |
| 15% | 6.7% | 长线，仓位自然小 |

**止损越近，仓位越大，但越容易被洗**；不是「止损近就安全」。用 ATR 或结构位定止损，再倒推仓位。

## 4. 跳空压力测试

A 股 T+1，止损不保证成交；按最坏跳空估算：

```text
跳空亏损 = 仓位比例 × 跳空幅度
```

| 仓位 | 主板 -10% | 创业板/科创板 -20% |
|---:|---:|---:|
| 10% | 1.0% | 2.0% |
| 12.5% | 1.25% | 2.5% |
| 20% | 2.0% | 4.0% |
| 30% | 3.0% | 6.0% |

如果 `跳空亏损 > 单笔风险预算`，要么减小仓位，要么接受「跳空是额外风险」，并在组合热力里预留缓冲。

## 5. 组合层面

1. **相关性聚类**：3 只半导体 ETF 不是 3 个独立仓位，按一个仓位算热力。
2. **总仓位**：[[@Fioona交易模式的简单分享]] 与 [[交易心得]] 都强调环境决定仓位；震荡市总仓位 <50%，趋势市可提高，但单笔风险不变。
3. **加仓**：只在盈利后加，不在亏损时补仓；[[下有界限，上不封顶，概率与盈亏比]] 明确「下跌补仓是散户被套的主因」。
4. **凯利公式（可选）**：`f* = p − (1−p)/R`；实际用 1/4–1/2 凯利，且受单笔风险上限约束。凯利是理论上限，不是目标仓位。
5. **回撤降档**：账户回撤 5% 时风险减半，回撤 10% 时暂停新开仓；先活下来。

## 6. 极端情形

1. **连续跌停**：止损单无法成交，实际亏损远超预算；2015、2024-02 都出现过。仓位是唯一可靠的控制。
2. **跳空**：隔夜消息/外盘导致开盘跳过止损；用上面的压力测试。
3. **流动性枯竭**：小票/ETF 买卖价差扩大，止损滑点大；加流动性过滤。
4. **相关性上升**：危机时所有持仓同跌，组合热力被低估；按压力情景重算。
5. **杠杆**：融资/期权会放大亏损；杠杆下的「1% 风险」要按保证金和强平线重算。
6. **心理扭曲**：[[交易心得]] 说仓位过重会让判断变形；[[金融心理学]] 的损失厌恶（痛苦约 2.5 倍）会让人不止损。仓位轻到能睡着，才执行得了规则。
7. **过度分散**：仓位太小、标的太多，交易成本和注意力被稀释；3–5 个独立逻辑足够。

## 7. 数据与实现

- 权益：账户总权益（含现金），不是可用资金。
- 止损：结构位/ATR/均线，先定止损再算股数。
- 风险比例：按策略的历史 MDD 和最大连亏调整；MDD 大的策略用更低的 r。
- 记录：每笔记录计划风险、实际亏损、是否跳空、是否按计划止损。

## 8. 回测与验证

- 假设（[[待验证策略看板]] U06）：固定 1% 单笔风险 + 严格止损 + 盈亏比 ≥1.5，长期期望为正且 MDD 可控。
- 方法：同一策略分别用 0.5%/1%/2% 风险回测，比较 CAGR、MDD、Calmar、破产概率。
- 压力测试：加入 -10%/-20% 跳空、连续跌停、相关性 1 的情景。
- 分段：2015、2018、2024-02、2024-09；至少 2 年样本外。
- 结论：仓位规则的目标不是收益最大化，而是「不死 + 可复利」。

### 回测结论（2026-10-24）：回撤控制有效，收益不成立

报告：[[BT-U06-盈亏比与止损]]｜看板：[[待验证策略看板]] U06

- 1% 单笔风险把组合 MDD 压到 54%–59%（无风险预算时 71.8%–84.6%），**回撤控制这一半有效**。
- 但同一套规则的入场信号单笔期望为负（−0.29%～−0.08%），仓位只能等比缩放亏损，**救不了负期望**；组合 CAGR −25.5%～−35.6%。
- 结论：本页规则按「不死 + 可复利」继续使用，但仓位必须挂在**已验证为正的入场信号**上；先有 alpha，再谈仓位。
