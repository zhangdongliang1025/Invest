# G03 保本价与动态止损线

> 来源：[[成本和动态止损线]]（成本线定义、保本触发阈值、4 种动态止损方案、两阶段执行流程与边界坑点）。
> 回答的问题：**止损线该放在哪？浮盈之后止损往哪挪？** 它管的是**离场的机械规则**，不产生 alpha——见 §6 的回测教训。

## 1. 定义

| 符号 | 含义 |
|---|---|
| `保本价` | 卖出后不亏不赚的价格，**必须包含买入佣金、过户费、卖出印花税**全部摩擦成本 |
| `初始风险 R` | `开仓价 − 初始止损价`（做空取相反） |
| `初始成本线` | 开仓那一刻的保本价 |
| `新成本线` | 加仓后按加权平均重算的保本价 |
| `ATR(14)` | 14 日平均真实波幅 |

> **关键区分**：**账面成本 vs 真实保本成本**。行情软件显示的持仓成本经常不含卖出印花税，必须自己单独记保本价。

## 2. 公式

```text
保本价（做多）= 开仓价 × (1 + 买入佣金率 + 过户费率) / (1 − 卖出佣金率 − 印花税率)

触发移至成本线的条件（二选一，或取先达成者）：
  浮盈 ≥ 1 × R        （浮盈达到初始风险的 1 倍）
  价格 ≥ 成本线 + 3%  （价格脱离成本 3%）

四种动态止损线：
  1. 百分比跟踪止损  多头：止损 = 持仓以来最高价 × (1 − N%)          例 N=8
  2. ATR 吊灯止损     多头：止损 = 持仓以来最高价 − N × ATR(14)        N ∈ {1.5, 2, 2.5}
  3. 波段高低点跟踪    多头：止损 = 最近一个有效波段低点下方一点
  4. 均线动态止损      多头：收盘价跌破 EMA/SMA(20 或 60) 离场
```

ATR 倍数的选择：**波动大的标的放大倍数，震荡市缩小**。

## 3. 判断标准：两阶段执行

这是本页最关键的结构，止损**不是一条线，是两个阶段**：

| 阶段 | 触发 | 止损行为 | 最坏结果 |
|---|---|---|---|
| **阶段 A** | 未达保本阈值（浮亏或小幅浮盈） | **使用初始止损，禁止上移**；浮亏时严禁下调 | 亏 ≤ 1R |
| **阶段 B** | 达保本阈值 | 止损上移至保本成本线 | 最多保本离场 |
| **阶段 C** | 阶段 B 之后创新高 | 按选定规则持续向上抬止损 | 带走大部分浮盈 |

> **禁止规则（原文明确）**：浮亏时向下放宽止损、下调成本线，属于典型的**风控破戒**。

## 4. 极端情形（坑点）

1. **跳空缺口**：动态止损是价格触发，隔夜大跳空会滑点，**ATR 也无法完全规避**。A 股 T+1 + 涨跌停，止损单不保证成交。
2. **震荡行情**：动态止损会反复被扫。原文建议**震荡市优先用固定止损，降低频率**。
3. **加减仓**：加仓会改变成本线，动态止损规则需重新评估，**不要直接沿用旧止损**。
4. **时间约束**：长线和短线的 ATR 倍数、回撤百分比**不能共用一套参数**。
5. **成交额与滑点**：止损线离盘口太近时，触线价不等于成交价；应按开盘/次价位预留滑点。
6. **样本内挑参数**：N = 1.5/2/2.5 是候选集，**必须样本外复核**，不能事后选最优（见 §6）。

## 5. 数据与实现

- 保本价：用**含全部费率的真实保本价**回测，卖出印花税 0.05% + 双边佣金 0.02%–0.03% + 过户费。
- ATR：Wilder 平滑，14 日；停牌与涨跌停日的真实波幅处理需固定。
- 触发时点：均为**收盘后确认、次日开盘执行**，禁止用当日收盘价既判定又成交。
- 跳空处理：若次日开盘已越过止损线，按开盘价成交（不假设能在止损价成交）。
- 记录字段（原文的复盘清单）：标的 / 开仓价 / 真实保本成本线 / 初始止损 / 保本触发阈值 / 动态止损规则 / 最终离场触发。

## 6. 回测与验证

- 假设（对应 [[待验证策略看板]] U26）：浮盈达到初始风险 1 倍（或价格脱离成本 +3%）后把止损上移至保本价，按此执行时整笔交易的实际亏损（含跳空滑点）显著小于固定比例止损；ATR 吊灯止损（N=1.5/2/2.5）在趋势行情优于固定止损。
- 方法：同一批入场信号，分别用「固定止损」「保本 + 固定跟踪」「保本 + ATR 吊灯」三套离场规则重跑，比较期望收益、胜率、盈亏比、MDD、最大单笔亏损、实际亏损 vs 计划亏损的偏离度。
- 样本：个股/指数分钟与日线；至少 3 年，IS/OOS 按 60/40 切分。
- 必须包含的成本：双边佣金 + 印花税 + 滑点 + 跳空成交价。
- 分组检验：ATR 倍数是 3 个候选值 + 固定止损 1 个基准 = 4 组，属多重检验，需做 Bonferroni 或 bootstrap 校正。

### 本库已有的相关教训（[[P0-回测总览]]）

- **U06 不通过**：盈亏比与严格止损是一套**风控框架**，不是 alpha。同样的规则下随机入场的期望、PF、R 胜率**全部更高**。本页的所有规则都属于「不死」范畴，**不能替代入场信号**。
- **U03 不通过**：原素材里的「跌破 20 日线止损」组合整体失败。止损规则的有效性必须与入场信号分开评估。

### 待验证的边界

1. **保本阈值的两种口径（1R vs 成本 +3%）哪个更优**：原文写「可自行修改」，未定。
2. **ATR 倍数与持有期不匹配时的表现**：短线用 ATR(14) 止损过宽。
3. **阶段 C 的抬止损频率**：每次新高都抬 vs 每 N% 抬，规则未固定。
4. **与持仓周期的耦合**：波段级（数周）与日内级参数必须分开，不能共用一套。
