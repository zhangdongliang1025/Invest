# Invest

个人投资知识库（Obsidian vault）。内容按「外部输入 → 自己验证 → 策略沉淀」流动。

## 三条铁律

1. `10-原始素材` 的**文字一字不改**：只做格式规范化（去时间戳、按语义分段、补 `内容摘要` 与 `## 正文` 标题），零改动由 `.backtest/verify_raw_normalize.py` 机械校验；`99-归档` 正文另受逐字节 sha256 约束，不做规范化。
2. 别人的观点默认 `unverified`，不许直接当结论使用；只有 `verified` 的策略卡才能进入实盘体系。
3. `20-自研沉淀` 的每条结论必须能回溯到素材链接或回测报告。

## 核心工作流

```text
新素材
  → 放入 10-原始素材 对应子目录
  → 加 frontmatter 标签（默认 unverified）
  → 规范化正文：去时间戳、按语义分段、补「内容摘要」与「## 正文」（文字不得改动）
  → 在「待验证策略看板」登记一行
  → 抽出可证伪假设，标 to-backtest
  → 回测并写报告到 22-回测与验证
  → 通过：写 21-策略卡片（verified）；不通过：素材标 deprecated 并归档
  → 实盘复盘写 23-复盘记录，并反向链接策略卡
```

## 双向链接规则

- 素材正文文字不改，因此**不在素材里加链接**；规范化只加 `内容摘要` 块与 `## 正文` 标题，不引入 wikilink。
- 统一由「沉淀笔记 → 素材」单向链接；素材页的 Backlinks 面板会自动显示所有引用，效果等同双向链接。
- 策略卡必须链接：来源素材 + 对应回测报告。

## 仓库说明

- 知识库主体是 Markdown + 图片，直接用 Obsidian 打开本目录即可。
- `.backtest/data/`（行情数据）与 `.backtest/venv/` 不入库，前者由 `.backtest/download_*.py` 重新获取。
- `.obsidian/workspace.json` 为本机 UI 状态，不入库。
- `.backtest/validate_links.py` 与 `.backtest/validate_status.py` 用于校验链接可解析性与 status/标签一致性。
- 重复素材的判定方法与逐文件 sha256 校验记录见 [[归档索引]]。
